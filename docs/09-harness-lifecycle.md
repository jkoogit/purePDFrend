# 09. 하네스 3계층 라이프사이클 및 상태머신 (Harness Lifecycle)

본 문서는 AI 에이전트와 엔지니어 간의 작업 신뢰성을 보장하기 위한 하네스 단계 전이 규칙을 정의합니다.

---

## 1. 단계별 상태머신 (State Transitions)

```
[ 세션 계층 ]
#세션시작 (Read-Only) ───► 작업 진행 ───► #세션정리 (Write: 회고/문서 동기화) ───► #세션종료 (DB 영속화)

[ 태스크 계층 ]
#태스크시작 (Read-Only) ──► #태스크처리 (Write 허용: 코드/문서작성) ──► #태스크정리 (검증/커밋) ──► #태스크승급 (Merge)

[ 루프 계층 ]
#루프분석 (Read-Only) ────► #루프실행/#루프처리 (Write 허용) ──────► #루프보완 (검증) ────────► #루프승인 (정리)
```

---

## 2. 파일 수정 권한 엄격 준수 규칙

| 단계 | 파일 수정 권한 | 비고 |
| :--- | :---: | :--- |
| **`#세션시작`** | ❌ 수정 불가 | DB 활성 세션 확인, 목표 수립 |
| **`#태스크시작`** | ❌ 수정 불가 | 작업 브랜치 확인, DB 태스크 '시작' 등록 |
| **`#태스크처리`** | 🟢 **수정 가능** | 소스 코드, 설정, 문서 작성 및 수정 수행 |
| **`#태스크정리`** | ❌ 수정 불가 | 빌드 및 테스트 검증, 커밋 생성 |
| **`#세션정리`** | 🟢 **수정 가능** | 회고 문서 작성, `/docs` 100% DB 동기화 |
| **`#세션종료`** | ❌ 수정 불가 | 토큰 집계 및 세션 최종 종료 |
