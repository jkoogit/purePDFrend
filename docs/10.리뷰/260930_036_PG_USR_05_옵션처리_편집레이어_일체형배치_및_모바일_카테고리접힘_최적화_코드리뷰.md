## 2. 세부 구현 및 개선 항목

### 2.1 옵션처리 편집레이어 네비게이션 `div` 미리보기 내부 일체형 배치 (`ImageEditLayerModal.tsx`)

1. **레이어 틀어짐 및 분리 현상 원인 규명**:
   - 기존 좌측 패널이 `justify-between`으로 상단 프리뷰 영역과 하단 페이지 네비게이션 영역으로 분리되어 있어, 화면 해상도나 모바일 세로 배치 시 프리뷰 캔버스와 네비게이션 간격이 과도하게 벌어지거나 스크롤이 비정상적으로 어긋나는 문제가 있었습니다.
2. **미리보기 컨테이너 내부 완전 일체화**:
   - **자르기(Crop) 탭**: 프리뷰 캔버스 및 `잘린 크기: ... px` 텍스트 바로 아래에 페이지 이동 컨트롤(첫/이전/인풋/다음/끝), `AI 자동 여백 감지` 버튼, 진행도 바가 담긴 `div`를 직접 내포시켰습니다.
   - **표준화(Standardize) 탭**: 규격 정보(`미리보기 210mm × 297mm (A4)`) 바로 아래에 페이지 이동 컨트롤과 진행도 바가 담긴 `div`를 직접 내포시켰습니다.
3. **4방향 드래그 앵커 클리핑 방지**:
   - 앵커 핸들의 위치를 `Math.max(4, ...)`로 안전하게 클램핑하여 여백이 0px이거나 모서리에 닿았을 때에도 드래그 핸들이 잘리지 않고 항상 온전하게 클릭 및 조작되도록 보정하였습니다.
4. **탭별 기능 격리 무결성**:
   - 자르기 전용 기능인 `AI 자동 여백 감지` 버튼을 '자르기' 탭에만 엄격히 한정하고, '표준화' 탭에는 불필요한 노출을 완전히 차단하였습니다.

### 2.2 모바일 모드 도서 카테고리 접힌 상태 배너 상시 노출 보장 (`DocumentLibraryViewer.tsx`)

1. **접힌 상태 소멸 버그 원인 규명**:
   - 기존 접힘 배너가 `isMobileMode && isCategoryCollapsed` 조건에만 바인딩되어 있어, 일반 브라우저 창 축소나 모바일 기기(뷰포트 `< 1024px`) 환경에서 `isMobileMode` prop이 false일 경우 데스크톱 분기인 `hidden lg:flex`가 적용되어 모바일 화면에서 카테고리 접힘 상태가 완전히 사라지는 문제가 발생했습니다.
2. **`isMobileMode` 및 모바일 해상도(`lg:hidden`) 전 구간 상시 표시**:
   - `isCategoryCollapsed`가 true일 때, 모바일 뷰포트에서는 화면 너비 전체를 차지하는 깔끔한 단일 접힘 배너(`📁 도서 카테고리 (위로 접힘) | 펼치기 ▼`)를 무조건 노출하도록 조건을 개선했습니다.
   - 배너 클릭 또는 [펼치기 ▼] 버튼 클릭 시 아래로 자연스럽게 펼쳐지며, 펼쳐진 상태에서는 헤더의 `ChevronUp` 버튼으로 언제든지 다시 위로 접을 수 있습니다.
3. **데스크톱 슬림 바(`PanelLeftOpen`)와의 상호 배타적 분기**:
   - 데스크톱 뷰(`hidden lg:flex`)에서는 기존의 세로 슬림 바(`lg:col-span-1`)와 우측 확장 버튼이 정상 작동하여, 데스크톱(좌우)과 모바일(상하) 접힘이 완벽한 시각적/기능적 조화를 이룹니다.
