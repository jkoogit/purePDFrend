## 1. 개요 및 목적

본 코드리뷰는 TASK-0027-02 과업에 따라 다음과 같은 목표를 달성한 결과를 종합 검토하고 품질을 보증합니다:
1. **단일 진실 공급원 디자인 토큰(`src/styles/tokens.ts`) 추출**:
   - 기존에 화면별로 난립하던 50여 가지 Tailwind CSS 색상과 임의의 크기/간격 값들을 **Brand(Blue-600)**, **Neutral/Gray(Slate)**, **Semantic(Success/Warning/Danger/Info)**, **Domain(PDF/Agent)** 4대 색상 체계와 4pt 베이스 간격/타이포그래피/반경 시스템으로 완전 규격화.
2. **와이어프레임 스튜디오 내 1급 탭 '디자인 시스템' 쇼케이스 구축 (`DesignSystemShowcase.tsx`)**:
   - `WireframeStudio.tsx`에 3번째 1급 탭(`showcase`)을 신설하여 개발자 및 기획자가 토큰 시스템 및 원자(Primitive) 컴포넌트(Button, Input, Badge, Card, Modal 등)의 상태별/변형별 렌더링 결과를 시각적으로 즉시 확인·검증할 수 있는 환경 제공.
3. **향후 전환 계획(3단계 Phase) 정립**:
   - Phase 1 (토큰 추출 및 쇼케이스 구축 완료)
   - Phase 2 (컴포넌트 3계층 Primitive/Composite/Layout 정립)
   - Phase 3 (PDF 핵심 MVP 3대 화면 USR-03 뷰어, USR-04 BBox 교정, USR-05 레이아웃 편집기 바인딩)

## 2. 주요 변경 내역 및 구현 상세

### 2.1 단일 진실 공급원 디자인 토큰 시스템 (`src/styles/tokens.ts`)
- **색상 시스템 규격화 (`tokens.colors`)**:
  - `brand`: primary(Blue-600), primaryHover(Blue-700), primaryActive(Blue-800), primaryLight(Blue-50/10)
  - `gray`: 50부터 950까지의 체계적인 Slate 팔레트
  - `semantic`: success(Emerald), warning(Amber), danger(Rose), info(Sky)
  - `domain`: pdf(Red-600/50), agent(Purple-600/50)
- **타이포그래피 시스템 (`tokens.typography`)**:
  - `display`: h1(28px/bold), h2(22px/bold), h3(18px/semibold)
  - `body`: lg(16px), md(14px), sm(12px), xs(11px)
  - `mono`: code(13px JetBrains Mono/Consolas)
- **간격 및 레이아웃 시스템 (`tokens.spacing`, `tokens.radius`, `tokens.shadow`, `tokens.touchTarget`)**:
  - 4pt 배수 기반 spacing (1: 4px ~ 16: 64px)
  - 반경(radius): sm(4px), md(8px), lg(12px), xl(16px), full(9999px)
  - 모바일 터치 타깃 가드레일: `minHeight: 44px`, `minWidth: 44px`
- **Tailwind 유틸리티 클래스 매핑 (`tokenClassMap`)**:
  - CSS in JS 객체뿐 아니라 Tailwind 클래스 문자열과의 직접 매핑을 제공하여 기존 JSX 마크업과의 호환성 완벽 보장.

### 2.2 디자인 시스템 쇼케이스 뷰 (`src/ppdf/views/wireframes/DesignSystemShowcase.tsx`)
1. **헤더 및 3대 전환 로드맵 시각화 카드**:
   - Phase 1(토큰 추출 완료), Phase 2(컴포넌트 3계층), Phase 3(PDF MVP 바인딩)을 단계별 카드 형태로 상단에 가시화.
2. **색상 팔레트 시각적 그리드**:
   - Brand, Gray Scale, Semantic, Domain 색상 블록과 HEX 코드, CSS 변수/Tailwind 클래스 실시간 프리뷰.
3. **타이포그래피 스케일 뷰**:
   - Display(H1~H3), Body(LG~XS), Mono 폰트 크기 및 샘플 텍스트 렌더링.
4. **원자(Primitive) 컴포넌트 인터랙티브 쇼케이스**:
   - Button (5종 variant: primary, secondary, danger, ghost, outline / 3종 size / disabled / loading)
   - Input (기본, 에러, 읽기전용, 성공 상태)
   - Badge (default, primary, success, warning, danger, outline)
   - Card (default, interactive 클릭 토글 인터랙션)
   - Modal (실제 팝업 열기/닫기 인터랙션 검증)
5. **모바일 뷰포트 반응형 지원**:
   - WireframeStudio의 데스크톱(100%), 태블릿(768px), 모바일(375px) 뷰포트 시뮬레이터와 100% 연동.

### 2.3 와이어프레임 스튜디오 네비게이션 확장 (`WireframeStudio.tsx`)
