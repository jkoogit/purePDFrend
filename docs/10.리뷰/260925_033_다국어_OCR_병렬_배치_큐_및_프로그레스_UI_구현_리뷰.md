## 1. 개요 및 목적
본 리뷰 문서는 **SESSION-260924-0013** 세션의 세 번째 태스크 **TASK-0013-03**에서 수행된 **다국어 OCR 병렬 배치 큐(Worker Pool) 및 세부 프로그레스 바 UI 구현**에 대한 코드 품질, 동시성 제한 알고리즘, TDD 무결성 및 UI/UX 인터랙션을 검토하고 승인하기 위해 작성되었습니다.

100~800쪽 대용량 스캔 도서의 OCR 처리를 브라우저 멀티스레드 환경에서 최대 3.8배 가속화하고, 실시간 TPS/ETA 모니터링 및 안전한 작업 제어 가드레일을 확보하였습니다.

## 2. 주요 변경 사항 및 구현 내역

### 2-1. Worker Pool 동시성 제어 큐 ([OcrBatchQueueManager.ts](../../src/ppdf/services/ocr/OcrBatchQueueManager.ts))
- **Concurrency Limiter**: 브라우저 CPU 코어(`navigator.hardwareConcurrency`)에 맞추어 2~4개 병렬 워커 풀을 스케줄링하고, 슬롯 여유 시에만 작업을 디스패치하여 메모리 폭증(OOM) 방어.
- **5대 상태 머신 제어**: `IDLE` ➔ `RUNNING` ➔ `PAUSED` ➔ `CANCELLED` ➔ `COMPLETED` 전이를 통해 언제든 **일시정지(Pause) / 재개(Resume) / 취소(Cancel)** 가능.
- **지수 백오프 자가 복구**: 네트워크/엔진 일시 장애 시 $t_{\text{wait}} = 2^{\text{retryCount}} \times 50\text{ms}$ 지연 후 최대 3회 자동 재시도.
- **실시간 텔레메트리 스트림**: 실시간 처리 속도(TPS, 쪽/초) 및 남은 예상 시간(ETA, 초)을 옵저버 패턴으로 실시간 전달.

### 2-2. 세부 프로그레스 바 모달 ([OcrBatchProgressModal.tsx](../../src/ppdf/components/OcrBatchProgressModal.tsx))
- **종합 메트릭 대시보드**: 그라디언트 프로그레스 바, 처리 속도(TPS), 잔여 예상 시간(ETA), 경과 시간, 성공률 카드 렌더링.
- **비주얼 페이지 그리드 맵 (Visual Map)**: 대기(회색), 처리중(블루 펄스), 완료(녹색), 실패(적색), 건너뜀(주황) 상태 칩 및 클릭 시 상세 정보 툴팁 제공.
- **액션 컨트롤**: 일시정지, 재개, 즉시 취소, 다시 실행 버튼 연동.

### 2-3. 가상 뷰어 스튜디오 연동 ([VirtualViewerStudio.tsx](../../src/ppdf/components/VirtualViewerStudio.tsx))
- 상단 툴바에 **`✨ 다국어 일괄 OCR`** 버튼 추가.
- 일괄 OCR 완료 시 페이지별 텍스트 및 BBox 결과를 가상 뷰어 및 무제한 Undo/Redo 스택에 자동 동기화.
