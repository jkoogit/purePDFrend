## 2. 5대 핵심 영역 구현 및 개선 상세 내역

### 1) PG-ADM-12 게시판·배너 관리 (본문 다중행, 첨부파일, 게시기간)
- **다중행 텍스트 에디터**: 공지사항 및 배너 등록/수정 모달에 단일 입력창 대신 4~5행 다중행 본문 `<textarea>` 적용.
- **필수 필드 완비**: 공지 제목, 첨부파일 업로드 및 파일명 표시, 게시 기간(시작일 ~ 종료일) 달력 입력 필드, 예약 공지 일시, 다시 열지 않기(하루/주/월) 옵션 완비.
- **배너 우선순위 순서**: 배너별 가로/세로 배너 이미지 첨부, 텍스트 여러줄 안내 문구, 노출 순서 번호 부여 및 사용 여부 토글 스위치 완비.
- **반응형 최적화**: 모바일 뷰포트에서 테이블 찌그러짐 없이 깔끔한 카드 형태로 자동 렌더링(Table-to-Card).

### 2) PG-ADM-13 고객관리 (버튼명 표준화, FAQ 수정 팝업, Q&A/1:1 답글 버튼 완비)
- **버튼 명칭 일원화**: 기존의 장황한 버튼명을 사용자 요청에 맞추어 간결한 **'저장'** 및 **'답글작성'**으로 일원화.
- **FAQ 수정 팝업 모달 신설**: FAQ 항목 수정 클릭 시 전용 팝업 모달을 오픈하여 카테고리, 질문, 답변을 직관적으로 수정하고 즉시 반영.
- **Q&A 및 1:1 상담 답글 액션 보강**:
  - 답변 대기 상태 티켓: `⚠️ 답변대기` 배지와 함께 눈에 띄는 **`[✍️ 답글작성]`** 버튼 제공 및 인라인 작성창 활성화.
  - 답변 완료 상태 티켓: **`[답글수정]`** 및 **`[답글삭제]`** 버튼을 추가하여 등록된 관리자 답변을 언제든 수정/삭제 가능하도록 보완.
  - 신규 등록 모달: 상단에 `[+ 신규 Q&A 질문 등록]` 및 `[+ 신규 1:1 상담 등록]` 모달을 추가하여 실시간 등록 및 테스트 동선 확보.
- **2-Depth 단일 스레드 거버넌스**: 무한 대댓글로 인한 모바일 UI 파손을 방지하고 공식 답변의 신뢰도를 유지하기 위해 고객 문의(Depth 1) ➔ 관리자 공인 답변(Depth 2) 구조 유지.

### 3) PG-ADM-14 무료글꼴관리 (1글꼴-다중파일 업로드 & 시원한 가로형 카드)
- **1글꼴-다중파일 업로드 지원**: 한 글꼴 패밀리(Regular, Bold, SemiBold 등)에 속한 다중 웨이트/포맷 파일을 한 번에 첨부하고 파일명 칩으로 동적 관리.
- **가로형 카드 레이아웃 전환**: 기존의 3열 세로 격자(`grid-cols-3`)에서 벗어나 **넓고 시원한 가로형 카드(`flex-col lg:flex-row`)**로 전면 개편.
  - **좌측**: 글꼴명, 포맷, 적용 상태 배지, 다중 첨부파일 칩 목록.
  - **중앙**: `font-family`가 실시간 반영되는 와이드 렌더링 프리뷰 텍스트 박스(텍스트 말줄임 없이 시원하게 표시).
  - **우측**: 순서 이동(▲/▼), 수정, 삭제, 뷰어 적용/해제 토글 버튼.
- **보기 전환 스위치**: `↔️ 가로형 카드 (기본)` vs `⊞ 격자형 카드` 전환 버튼 제공.

### 4) PG-ADM-15 단축키 및 도구아이콘 관리 (복합 기능키, 아이콘 첨부, 가로형 카드 줄바꿈)
- **복합 기능키(Ctrl+Shift+Alt) 조합**: 기능키 체크박스(Ctrl, Shift, Alt)와 주 키 입력 필드를 조합하여 복합 단축키(예: `Ctrl + Shift + F`)를 손쉽게 설정 및 해제.
- **도구 아이콘 첨부파일 업로드**: 도구별 디자인 리소스 프리셋 선택 외에 사용자 커스텀 SVG/PNG/ICO 아이콘 파일 첨부 기능 완비.
- **가로형 카드 & 너비 초과 시 자동 줄바꿈(flex-wrap)**:
  - 컨테이너에 `flex flex-wrap gap-3.5 items-stretch`를 적용하고 각 카드에 `min-w-[280px] flex-1 basis-[320px] max-w-[460px]`를 부여.
  - 화면 및 부모 너비가 초과할 경우 자연스럽게 다음 행으로 줄바꿈되어 반응형 모바일/태블릿/데스크톱 전 구간에서 최적 렌더링.
- **상단 보기 전환**: `🗂️ 가로형 카드 (자동 줄바꿈)` vs `📋 테이블 보기` 전환 버튼 구비.

### 5) PG-ADM-09 & PG-ADM-10 API 연동관리 화면 단일화
- **단일 화면 통합**: 별도로 나뉘어 있던 `PG-ADM-09`(내부 API)와 `PG-ADM-10`(외부 API)을 **`PG-ADM-09: API 연동관리 (내부/외부 통합)`** 단일 프로그램으로 일원화.
- **상단 통합 요약 대시보드**: 총 등록 API, 내부 서비스 엔진 가동 건수, 외부 연동 가동 건수 3대 핵심 메트릭 카드 상시 노출.
- **단일 목록 탭 필터 및 통합 등록**: `전체 통합 API` / `⚙️ 내부 서비스 API` / `🌐 외부 연동 API` 탭 필터와 신규 통합 등록 팝업 모달 제공.
