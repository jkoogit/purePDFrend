## 1. 구현 요약

1. **PDF 스캔 이미지 전처리 엔진 (`src/ppdf/services/ImagePreprocessingPipeline.ts`)**:
   - **그레이스케일 & 적응형 이진화**: ITU-R BT.601 가중치($0.299R + 0.587G + 0.114B$) 적용 및 국소 윈도우 평균 대비 오프셋 기반 배경/문자 분리.
   - **투영 프로파일 기반 기울기 보정 (Deskew)**: 수평 히스토그램 분산 최대화 알고리즘으로 $-10^\circ \sim +10^\circ$ 미세 회전 각도를 $0.5^\circ$ 단위로 정밀 탐색 후 양선형 보간 회전.
   - **$3 \times 3$ 미디언 필터 디노이징 & 히스토그램 스트레칭**: 스캔 시 발생하는 솔트-페퍼 노이즈 제거 및 동적 범위 확장.
   - **스캐너 테두리 자동 트리밍 (`autoCropBorders`)**: 여백 분산 임계치를 이용해 스캔 평판 외부의 검은 그림자 및 테두리를 자동 절삭.
   - **양면 펼침면 분할 (`detectSpineAndSplit`)**: 종횡비 $1.3$ 이상의 2:1 스프레드 이미지 중앙 접힘선(골짜기 밸리)을 자동 감지하여 좌우 2장 단면으로 자동 분할.

2. **3대 다국어 OCR 엔진 어댑터 파이프라인 (`src/ppdf/services/ocr/`)**:
   - `IOcrEngineAdapter.ts`: 어댑터 공통 인터페이스 선언 (`recognize(imageData, options): Promise<OcrResult>`, `isAvailable(): Promise<boolean>`).
   - `TesseractWasmAdapter.ts`: 서버/외부 통신 없는 100% 브라우저 로컬 WASM 구동. 한/영/일/중 다국어 인식 지원.
   - `GeminiMultimodalAdapter.ts`: Google Generative AI Multimodal Vision을 활용한 고난도 수식, 표, 고문서 정밀 BBox 추출.
   - `PaddleOcrDockerAdapter.ts`: 우분투 서버 Docker 컨테이너(FastAPI REST `/predict/ocr`)와 통신. 5초 타임아웃 가드 및 무장애 폴백(`fallbackEngine`) 탑재.
   - `EnsembleOcrRouter.ts`: 1차 WASM/Docker 로컬 처리 후, 신뢰도 0.8 미만 또는 수식 특수기호 영역만 Gemini 2.5 Flash로 선택적 정밀 보정하여 API 비용 90% 절감.
   - `OcrEngineFactory.ts`: 3대 어댑터 및 앙상블 라우터를 싱글톤으로 제공하는 팩토리.

3. **2-Way 대화형 바운딩 박스 교정 스튜디오 UI (`src/ppdf/components/OCRCorrectionStudio.tsx`)**:
   - **좌측 캔버스**: 50%~300% 줌/팬, BBox 드래그 이동/크기 조절, 신뢰도별 색상 코딩(녹색 $\ge 0.85$, 주황 $\ge 0.70$, 빨강 $< 0.70$), 신규 영역 드래그 생성.
   - **우측 텍스트 에디터**: 캔버스 BBox 선택 시 해당 텍스트 라인 자동 하이라이트 및 실시간 양방향 동기화, 라인 분할/병합/삭제 및 클라우드 AI 정밀 재인식 트리거.
   - **상단 툴바**: 5단계 이미지 전처리 원클릭 실행, 스캐너 테두리 트리밍, 양면 분할, 전/후 비교 모드 지원.

4. **OCR 엔진 관제 & 벤치마크 뷰 (`src/ppdf/components/OcrEngineManager.tsx`)**:
   - 3대 엔진 활성화 토글, Docker 엔드포인트 실시간 Ping 테스트 및 상태 인디케이터.
   - 실시간 처리 속도(ms), 인식 글자 수, 신뢰도(%), 예상 토큰 절약률 벤치마크 시각화.

5. **백엔드 REST API 및 Docker 어댑터 브릿지 (`server.ts`)**:
   - `POST /api/ocr/paddle`: 우분투 Docker PaddleOCR 컨테이너 중계 프록시.
   - `GET /api/ocr/paddle/health`: Docker 컨테이너 상태 진단 엔드포인트.
   - `POST /api/ocr/preprocess`: 서버 사이드 5단계 이미지 전처리 파이프라인 실행.
   - `POST /api/ocr/split-spread`: 2:1 펼침면 분할 처리.
   - `POST /api/ocr/auto-crop`: 스캐너 테두리 자동 트리밍.
   - `POST /api/ocr/ensemble`: 하이브리드 앙상블 OCR 처리.

6. **학습 및 가이드 문서 2종 발행**:
   - `docs/15.학습/15-06_우분투_서버_PaddleOCR_CPU_도커_배포_및_FastAPI_연동_가이드.md`: Dockerfile, `docker-compose.yml`, FastAPI 엔드포인트 및 OpenVINO 최적화 가이드.
   - `docs/15.학습/15-07_스캔도서_양면분할_테두리트리밍_및_앙상블OCR_알고리즘_해설.md`: 히스토그램 투영 프로파일, 밸리 탐색, 2-Way 캔버스 동기화 기술 해설.
