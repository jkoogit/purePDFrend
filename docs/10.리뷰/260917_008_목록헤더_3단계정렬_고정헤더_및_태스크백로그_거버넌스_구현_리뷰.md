## 3. 세부 구현 내역

### 3.1 목록 헤더 3단계 순환 정렬 (3-State Cyclic Sorting)
- **적용 화면**: `AgentUsageViewer` (턴#, Trace ID, 루프ID, 모델, 프롬프트, 응답, 시각), `TaskInfoManager` (세션/태스크/루프 전체 테이블 컬럼)
- **작동 원리**:
  - 1회 클릭: **오름차순(asc)** (`ArrowUp` 아이콘 표시)
  - 2회 클릭: **내림차순(desc)** (`ArrowDown` 아이콘 표시)
  - 3회 클릭: **초기화(init)** (기본 순서 복원, `ArrowUpDown` 비활성 아이콘)

### 3.2 고정 헤더 (Sticky Top Header)
- 테이블 컨테이너에 `relative overflow-auto`를 설정하고, `<thead>`에 `sticky top-0 z-20 bg-slate-900 shadow-md`를 일괄 적용하여 세로 스크롤 시에도 헤더 컬럼이 항상 상단에 고정 표시되도록 보장.

### 3.3 대화 턴 응답정보 현행화
- 이번 세션에서 수행된 17개 대화 턴 전체의 요청 전문, 응답 전문(Markdown 서식 포함), 루프ID, 요약문을 DB에 실시간 현행화.

### 3.4 태스크 항목분할 및 백로그 거버넌스 운영정책 제정
- `docs/03.정책/03-08_태스크_항목분할_및_백로그_거버넌스_운영정책.md` 신설.
