## 1. 개요 및 목적

본 코드리뷰는 세션 0033의 잔여 백로그(`BACKLOG-0032-03`)였던 **하네스 메타원장(세션, 태스크, 루프) DDL 스키마 정합성 확보 및 도메인 레포지토리 리팩토링(`TASK-0033-02`)**의 구현 및 검증 결과를 다룹니다:

1. **PostgreSQL 물리 DDL 100% 정합 스키마 정규화**:
   - `aiagent.harness_task_meta` 테이블에 부재한 `priority`, `assigned_agent` 컬럼을 DDL 컬럼에서 안전하게 격리하고 `doc_payload`(JSONB)로 보존.
   - `aiagent.harness_loop_meta` 테이블의 `started_at` `NOT NULL` 제약조건을 시스템 기본값으로 강제 보장.
2. **도메인 레포지토리 패턴(`HarnessRepository.ts`)을 통한 듀얼 영속화 일원화**:
   - `data/local_agent_store.json` 로컬 파일과 원격 PostgreSQL DB 간의 갱신 로직을 단일 파사드로 통합.
   - 원격 DB 타임아웃(5,000ms) 및 연결 장애 시 UI나 에이전트 작업이 정지되지 않고 로컬 상태로 안전하게 폴백하는 **Zero-Hang Principle (정책 02-05)** 구현.
3. **Express 서버 RESTful 쓰기 엔드포인트 확장**:
   - `POST /api/agent/sessions`, `POST /api/agent/tasks`, `POST /api/agent/loops` 3대 표준 API 장착.
