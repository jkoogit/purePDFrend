### 2-1. [1단계] 단위 테스트 점검

  - `TC-02`: 도서 상세 서지 정보 12종 무결성 검증
  - `TC-03`: 유니코드 다국어(한글, 한자 漢字, 특수기호 ★✨) 100% 무손실 복원
  - `TC-04`: 활동 정보 4대 분류 및 사용자 연계 속성 검증
  - `TC-05`: 독서 2독 회독 상태 및 50% 진도율 계산 검증
  - `TC-06`: 바이트 스트림 레벨 무결성 100% 보존 검증
  - `TC-07`: 커스텀 메타데이터 안전 삭제 및 표준 필드 보존 검증
  - `TC-08`: 회독 차수 승급(`nextRound()`) 시 `roundHistory` 누적 보존 검증
  - `TC-09`: ISBN-10/13 체크섬 유효성 검증 및 `priceFormatted` 포맷터 검증
  - `TC-10`: 다중 사용자(`userId`)별 독립 독서/활동 분리 관리 검증
  - `TC-11`: `PdfMetadataBundleFactory` 및 `PdfMetadataFacade` 상호운용성 검증

### 2-2. [2단계] DDD(도메인 주도 설계) 및 불변 객체 점검
- **불변 값 객체(Immutable VO)**:
  - `BookBibliographicInfo`, `BookActivityInfo`, `BookReadingProgress` 내 모든 배열 속성에 `Object.freeze`와 방어적 복사 적용.
  - 상태 변경 시 원본 객체를 수정하지 않고 새로운 불변 객체를 생성·반환(Pure Mutation).
- **애그리게이트 루트 (`PdfMetadataBundle`)**:
  - 표준 8대 메타데이터와 서지·활동·독서 하위 도메인을 일관된 생명주기로 통제.

### 2-3. [3단계] 아키텍처 및 디자인 패턴 점검
- **헥사고날 아키텍처**:
  - `IPdfMetadataPort` 인터페이스를 통해 비즈니스 계층이 `pdf-lib` 구현 세부사항과 직접 결합되지 않도록 역전(DIP).
- **파사드 패턴 (`PdfMetadataFacade`)**:
  - UI 컴포넌트(`ScenarioDesignView` 등)에서 회독 승급, 페이지 진도 갱신, 검증을 단 한 번의 호출로 수행.
- **팩토리/빌더 패턴 (`PdfMetadataBundleFactory`)**:
  - 누락된 속성을 출판사/저자 기반으로 자동 추론하고 정합성을 자동 보정.

### 2-4. [4단계] 보안 및 런타임 안정성 점검
- `pdf-lib` 내부 비공개 메서드(`getInfoDict()`) 접근을 제거하고, 공개 인터페이스인 `pdfDoc.context.lookup(trailerInfo.Info)`를 사용하여 타입 안정성과 런타임 보안 확보.
- XSS 및 인젝션 방어: PDF 딕셔너리 주입 시 `PDFHexString`을 통해 16진수 바이트 단위로 패킹하여 스크립트 실행 위험 차단.

### 2-5. [5단계] 논리적 결함 보완 및 정합성 가드
- 회독 승급 시 과거 이력 유실 결함을 `roundHistory`를 도입하여 완벽 방어.
- `currentPage > totalPage` 오버플로우 방지 클램핑 로직 구현.
- ISBN-10/13 체크섬 유효성 검증으로 비정상 도서번호 차단.

### 2-6. [6단계] 빌드 및 문서 인덱스 현행화
- `tsc --noEmit` 정적 린트 무결성 100% 통과 (에러 0건).
- `vite build` 정상 컴파일 완료.
- 설계서(`05-19`), 학습문서(`15-06`), 리뷰문서(`10-24`) 상호 인덱싱 완료.
