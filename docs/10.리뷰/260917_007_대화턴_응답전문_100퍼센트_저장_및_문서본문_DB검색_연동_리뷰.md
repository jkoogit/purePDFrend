## 1. 구현 요약

### 1.1 대화 턴 응답전문(Markdown 100%) 영속화
- **DB 테이블**: `aiagent.agent_conversation_trace`
- **개선점**: 기존 축약형 응답 텍스트를 배제하고, 마크다운 표, 인라인 코드, JSON/SQL 코드블록, 후처리 체크리스트가 모두 포함된 원본 100% 전문을 `agent_response` 컬럼에 저장.
- **검색 및 뷰어**: `AgentUsageViewer`와 `TaskInfoManager` 대화턴 감사 팝업에서 본문 단어 검색 시 일치하는 턴이 즉시 필터링되며, `Markdown` + `remarkGfm` 엔진을 통해 원문 서식 그대로 렌더링.

### 1.2 18대 기술문서 본문(doc_payload) 전수 적재 및 PostgreSQL JSONB 검색
- **DB 컬럼**: `aiagent.agent_docs_meta.doc_payload`
- **적재 데이터**: `{ folder, fileName, lines, size, content, lastModified }`
- **검색 쿼리**:
  ```sql
  SELECT doc_id, doc_title, folder_name, file_name 
  FROM aiagent.agent_docs_meta 
  WHERE title ILIKE '%키워드%' OR file_path ILIKE '%키워드%' OR (doc_payload->>'content') ILIKE '%키워드%';
  ```
- **UI 기능**: 문서 거버넌스 관리자 상단에 `[DB 본문 검색]` 토글 버튼 및 검색창 제공, 일치 문서에 `[본문 일치]` 태그 부착.
