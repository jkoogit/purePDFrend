## 1. 개요 및 목적

본 코드리뷰는 TASK-0027-01 과업에 따라 상단 글로벌 네비게이션 헤더(`Navbar`)에 원클릭 Sun/Moon 테마 스위처를 구축하고, 관리자 시스템서비스 1단계(PG-ADM-01 보안 IP 관리, PG-ADM-03 사용자 계정 관리)를 정적 Mock 상태에서 실제 백엔드 Express REST API 및 PostgreSQL/로컬 스토어 듀얼 영속화 파이프라인으로 전환한 내역을 종합 검토하고 품질을 보증합니다.

## 2. 주요 변경 내역 및 구현 상세

### 2.1 상단 글로벌 네비게이션 테마 스위처 (`Navbar.tsx`)
1. **Sun / Moon 테마 토글 버튼 (`#btn-theme-toggle`)**:
   - `Sun` 및 `Moon` 아이콘을 이용한 원클릭 다크/라이트 모드 스위처 탑재.
   - `localStorage` 키 `purepdfrend_theme` 영속화 및 `document.documentElement`의 `.dark` / `.light` 클래스 즉시 동기화.
   - OS 환경 선호도(`prefers-color-scheme`) 자동 감지 기본값 지원.
2. **와이어프레임 퀵액션 바로가기 (`#btn-quick-wireframes`)**:
   - 상단 헤더 우측 도구 영역에 와이어프레임 바로가기 버튼을 배치하여 사용자가 언제든 16개 관리자 및 9개 사용자 화면 와이어프레임으로 1클릭 전환 가능.
3. **모바일 햄버거 드로어 내 테마 스위처 (`#btn-mobile-drawer-theme-toggle`)**:
   - 모바일 환경에서도 손쉽게 테마를 변경할 수 있도록 드로어 푸터에 44px 최소 터치 타깃 가드레일을 준수한 전용 스위치 바 배치.

### 2.2 PG-ADM-01 보안 IP 관리 REST API 및 UI 바인딩
1. **Express 백엔드 엔드포인트 (`server.ts`)**:
   - `GET /api/admin/security/ips`: 화이트리스트 CIDR 대역 및 긴급 차단 블랙리스트 목록 반환.
   - `POST /api/admin/security/ips`: 신규 CIDR 대역 및 IP 차단 엔트리 등록.
   - `DELETE /api/admin/security/ips`: 특정 IP의 화이트리스트/블랙리스트 제외 처리.
   - `POST /api/admin/security/config`: 2단계 인증 전사 강제화, 해외 IP 차단(Geo-Blocking), 오프라인 토큰 수명 정책 실시간 동기화.
2. **UI 컴포넌트 바인딩 (`AdminSecurityView.tsx`)**:
   - 마운트 시 실제 API를 호출하여 최신 보안 정책 및 IP 목록을 렌더링하고, 추가/삭제/설정 변경 시 백엔드와 실시간 양방향 통신 수행.
   - 로딩 피드백 및 등록/삭제 완료 토스트 알림 완비.

### 2.3 PG-ADM-03 사용자 계정 관리 REST API 및 UI 바인딩
1. **Express 백엔드 엔드포인트 (`server.ts`)**:
   - `GET /api/admin/users`: PostgreSQL `aiagent.agent_user_account` 연계 및 로컬 인메모리 관리자 시드 데이터와 병합 조회.
   - `POST /api/admin/users`: 관리자 직접 신규 사용자 계정 등록.
   - `PATCH /api/admin/users/:id`: 다중 역할(`roles`), 계정 상태(`정상`, `제한`, `휴면`), 오프라인 사용 권한 동적 수정.
   - `DELETE /api/admin/users/:id`: 사용자 계정 삭제.
2. **UI 컴포넌트 바인딩 (`AdminUsersView.tsx`)**:
   - 실제 API 기반 회원 목록 로드 및 신규 등록 모달(`+ 회원 등록`), 다중 역할 체크박스, 회원 상태 원클릭 변경, 계정 삭제 완결.
   - 화면 폭 < 768px 모바일 환경에서 0px 가로 스크롤 Break-to-Card 완결성 유지.
