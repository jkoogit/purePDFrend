## 1. 개요 및 목적

본 코드리뷰는 사용자 포털 화면(PG-USR-01 ~ PG-USR-09) 및 와이어프레임 상단 헤더 레이어에서 제기된 UI/UX 개선 요청, 프로필 관리 및 인증 체계의 동선 단절 문제를 해결하기 위해 진행된 작업의 무결성과 코드 품질을 점검합니다.

특히 기존에 겉돌던 2FA 인증수단 재설정 버튼과 분리되어 있던 이메일 정보수정 및 인증 프로세스를 **하나의 연속된 인라인 동선으로 통합**하고, **시스템 정책에 따라 이메일 인증, 소셜 로그인, 2FA 강제화 여부를 유연하게 선택(옵션화)할 수 있도록 전면 고도화**하였습니다.

## 2. 세부 구현 및 개선 항목

### 2.1 상단 탑 레이어(WireframeTopLayer) 모바일 방어 및 퀵설정 UX 혁신
1. **모바일 뷰포트 좌측 잘림 원천 방어**:
   - 프로필 팝업 레이어의 너비(`w-[290px] xs:w-[305px] max-w-[calc(100vw-28px)]`) 및 우측 오프셋(`right-[-6px] sm:right-0`)을 최적화하여 360~390px 스마트폰 화면에서도 좌측 최소 40px 이상의 안전 여백 확보.
2. **퀵설정 및 고정 아이콘 크기·기준선 완벽 통일**:
   - 퀵설정 상단 텍스트 라벨을 삭제하고, 좌측 퀵설정 아이콘들과 우측 고정 버튼 4종(AI봇, 관리자, 설정, 로그아웃)의 크기를 `w-8 h-8 rounded-xl (32px)`로 일원화하고 단일 수평 기준선에 정렬.
3. **퀵설정 롱프레스 드래그앤드롭(DnD) 순서 재배치**:
   - ◀/▶ 버튼을 삭제하고 0.28초 롱프레스 시 아이콘이 둥실 떠오르는 시각 피드백(`scale-110 -translate-y-2 ring-2 ring-amber-400`), 드래그 시 목표 지점에 네온 앰버 가이드바(`w-1 h-7 animate-pulse`) 표시 및 드롭 시 순서 즉시 재배치 구현.
4. **링크 텍스트의 버튼 인식 표현(Button Affordance)**:
   - 텍스트 링크 형태에서 클릭 가능한 버튼 필(Pill button: `bg-slate-800 hover:bg-sky-600 border border-slate-700 font-semibold shadow-xs`) 형태로 전면 개편.
5. **50:50 균등 분할 취소 및 고정 아이콘 독립 너비 우선 확보**:
   - 우측 고정 버튼 4종에 `shrink-0` 너비를 보장하고, 중앙에 수직 구분선(`|: w-[1.5px] h-5 bg-slate-700/90`)과 좌우 마진(`mx-2.5 sm:mx-3`)을 배치하여 겹침 방지.

### 2.2 사용자관리(PG-USR-04) 프로필 사진 연필(✏️) 수정 및 캔버스 크롭 모달 연동
1. **톤다운 연필 버튼 배치**:
   - 원형 아바타 우측 하단에 튀지 않는 차분한 슬레이트 톤 연필(`Pencil`) 버튼 직결.
2. **최상위 레이어 크롭 & 프리셋 모달 연동**:
   - 기존에 PG-USR-02 내부에 갇혀 있던 [사진 자르기 팝업]과 [12종 프리셋 모달]을 컴포넌트 최상위 레이어로 승격시켜, 마이페이지(`PG-USR-04`)에서 연필 클릭 시 화면 이동 없이 제자리에서 크롭 뷰포트가 즉각 팝업되도록 완결.
   - 드래그 위치이동, 4방향 모서리 리사이즈, HTML5 Canvas 자르기 적용 시 마이페이지 아바타 즉시 갱신.

### 2.3 회원 기본정보 인라인 수정 모드 및 이메일 인라인 인증 통합
1. **읽기 모드 vs 인라인 편집 모드 전환**:
   - `[✏️ 기본정보 수정]` 클릭 시 모달 없이 요약 카드 내부가 인라인 편집 그리드 폼(실명, 별명 중복확인, 휴대폰 번호, 계정 이메일)으로 매끄럽게 전환.
2. **이메일 변경 시 제자리 인라인 인증 발송·검증 연속 동선**:
   - 이메일을 변경하면 입력창 우측에 `[인증번호 발송]` 버튼이 즉시 활성화됨.
   - 클릭 시 하단으로 `[6자리 번호 입력] [02:59] [인증 확인]` 확장 서랍이 열리며, 인증번호 확인(`482910`) 성공 시 `✓ 인증완료` 뱃지 점등.
3. **이메일 인증 시스템 정책 옵션화**:
   - `이메일 인증정책: [필수 🔒] / [선택(생략가능) 🔓]` 스위치 지원.
   - 필수 정책일 때는 새 이메일 인증이 완료되어야 `[저장하기]` 버튼이 활성화되어 보안 무결성 보장.

### 2.4 2FA 및 소셜로그인 시스템 정책 연동 & 비상 복구코드 10개 모달
1. **시스템 정책 스위처**:
   - `2FA 정책: [강제 필수 🔒] / [사용자 선택 🔓]`
   - `소셜로그인 정책: [연동 허용 ON] / [연동 차단 OFF]`
2. **2FA 사용자 자율 토글**:
   - 정책이 '선택'일 때 사용자가 `[2FA 켜짐 (ON) / 꺼짐 (OFF)]`를 자유롭게 토글 가능.
3. **주 2차 인증 수단(Primary Method) 1클릭 라디오 선택**:
   - 🟡 카카오 알림톡 (기본 권장)
   - 🔵 구글 OTP / Authenticator
   - 🟢 네이버 2차인증
   - ✉️ 이메일 인증번호
   - 원하는 수단 클릭 시 즉시 `주수단`으로 지정.
4. **비상 복구코드 10개 조회 및 관리 전용 모달 (`isBackupCodeModalOpen`)**:
   - 모호했던 재설정 버튼을 `[🔐 비상 복구코드 10개 조회 및 관리]`로 개편.
   - 일회용 8자리 복구코드 10개 2열 그리드 표시, `[📋 코드 전체 복사]`, `[🔄 새 코드 재발급]` 기능 완비.
