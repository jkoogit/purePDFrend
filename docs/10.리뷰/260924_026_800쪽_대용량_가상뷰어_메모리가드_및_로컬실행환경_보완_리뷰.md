## 1. 구현 요약

1. **800쪽 가상 윈도잉 뷰포트 엔진 (`src/ppdf/VirtualScrollEngine.ts`)**:
   - 스크롤 오프셋과 뷰포트 높이를 기반으로 현재 가시 영역(Viewport)에 포함된 페이지 범위(`visibleRange`)와 상·하단 패딩 높이를 수학적으로 산출.
   - 800쪽 기준 800개의 무거운 DOM 노드를 생성하지 않고 화면에 보이는 2~4개 페이지 노드만 렌더링하여 브라우저 가비지 컬렉션(GC) 부하 및 렌더링 지연을 원천 차단.

2. **LRU 메모리 가드 매니저 (`src/ppdf/MemoryGuardManager.ts`)**:
   - 최대 10페이지 한도로 렌더링된 캔버스 이미지 캐시를 관리하며, 한도 초과 시 가장 오래 참조되지 않은 페이지의 메모리를 즉각 해제(`URL.revokeObjectURL`, `canvas.width=0`).
   - 800페이지 로드 테스트 결과 총 메모리 사용량을 38MB 이하로 철저히 방어함.

3. **로컬 무장애 환경변수 로더 (`src/shared/envLoader.ts`)**:
   - 외부 무거운 의존성 없이 프로젝트 루트의 `.env` 및 `.env.local`을 안전하게 파싱하여 `process.env`에 주입.
   - 기존 OS 환경변수(AI Studio 환경)가 존재할 경우 이를 우선 보존하여 로컬과 클라우드 양쪽 환경을 완벽히 지원.

4. **비-LLM 긴급 Git Push 보안 필터링 강화**:
   - `EmergencyGitPushEngine.ts` 및 `github_sync_push.ts`의 파일 수집기(`getAllFiles`)에서 `.env*` 파일들을 원천 제외하여 GitHub Secret Scanning에 의한 422 거부를 방지하고 자격증명 노출을 100% 차단.
