## 1. 개요 및 목적

본 코드리뷰는 **`docs/07.로드맵/07-02_화면별_디자인_토큰_적용현황_및_단계별_로드맵.md`**에 명시된 **Phase 1 대상 핵심 사용자 화면 3종(`PG-USR-02`, `PG-USR-03`, `PG-USR-04`)**의 레거시 하드코딩 다크 스타일 클래스를 공식 **`src/styles/tokens.ts`** 디자인 시스템 유틸리티로 전면 전환하고, 4모드(Light, Dark, Dawn, System) 테마 환경에서의 무결성을 검증하고 품질을 보증합니다:

1. **하드코딩 인라인 다크 클래스 전면 퇴출**:
   - 기존 `bg-slate-900`, `bg-slate-950`, `border-slate-800`, `text-slate-200` 등으로 분산되어 있던 임의의 Tailwind 클래스를 제거하고, `tokens.ts`의 `getThemeAdaptiveClasses(theme)` 유틸리티 객체(`themeClasses.card`, `themeClasses.panel`, `themeClasses.input`, `themeClasses.buttonSecondary`, `themeClasses.tabActive`, `themeClasses.tabInactive` 등)로 100% 일원화.
2. **4모드(Light, Dark, Dawn, System) 실시간 테마 스위칭 및 WCAG AA 고대비 가독성 보장**:
   - 글로벌 Navbar의 테마 스위처 전환 이벤트(`MutationObserver` on `data-theme` + `storage` 이벤트)를 감지하여 캔버스 및 와이어프레임 하위 전 컴포넌트가 즉시 적응.
   - Light 모드에서는 깔끔한 백색/연회색 톤과 짙은 명조 텍스트, Dawn 모드에서는 딥 네이비톤(`bg-[#0e1a38]`), Dark 모드에서는 슬레이트 다크톤을 정확히 부여하여 WCAG AA 4.5:1 이상의 가독성 확보.
3. **44px 모바일 최소 터치 타깃 및 Zero-Pill 라운딩 규격 100% 준수**:
   - 모든 주요 대화형 버튼(로그인, 가입, 인풋, 소셜 버튼, 탭, 액션 버튼)에 `min-h-[44px]` 규격 적용.
   - 아바타 및 원형 아이콘을 제외한 모든 직사각형 카드, 모달, 패널, 인풋에 `rounded-xl`, `rounded-2xl` 적용 (알약형 `rounded-full` 배제).

## 2. 주요 변경 내역 및 상세 구현

### 2.1 `src/styles/tokens.ts` 테마 적응형 헬퍼 확장
- Light, Dawn, Dark 3대 테마에 걸쳐 보조 버튼 및 탭 상태를 일관되게 표현할 수 있도록 토큰 객체 확장:
  ```typescript
  export function getThemeAdaptiveClasses(theme: ResolvedTheme) {
    if (theme === 'light') {
      return {
        // ... 기존 토큰
        buttonSecondary: 'bg-slate-100 hover:bg-slate-200 text-slate-700 border-slate-300',
        tabInactive: 'bg-slate-100 hover:bg-slate-200 text-slate-600 border-slate-200',
        tabActive: 'bg-white text-sky-600 border-sky-500 shadow-sm font-bold',
      };
    }
    if (theme === 'dawn') {
      return {
        // ... 기존 토큰
        buttonSecondary: 'bg-[#14234b] hover:bg-[#1c3066] text-slate-200 border-[#223974]',
        tabInactive: 'bg-[#0f1d3f] hover:bg-[#162752] text-slate-300 border-[#1c3066]',
        tabActive: 'bg-[#1e346f] text-sky-300 border-sky-400 shadow-sm font-bold',
      };
    }
    // dark
    return {
      // ... 기존 토큰
      buttonSecondary: 'bg-slate-900 hover:bg-slate-800 text-slate-300 hover:text-white border-slate-700',
      tabInactive: 'bg-slate-900 hover:bg-slate-800 text-slate-400 border-slate-800',
      tabActive: 'bg-sky-950/60 text-sky-300 border-sky-500 shadow-sm font-bold',
    };
  }
  ```

### 2.2 `src/ppdf/views/wireframes/UserWireframes.tsx` 테마 연동 및 컴포넌트 치환
- **최상단 테마 감지 훅 선언**:
  ```tsx
  const [activeTheme, setActiveTheme] = useState<ThemeMode>(() => {
    return (localStorage.getItem('purepdfrend_theme_mode') as ThemeMode) || 'system';
  });
  // MutationObserver를 통해 documentElement의 data-theme 변경 실시간 추적
  const resolvedTheme = resolveThemeMode(activeTheme);
  const themeClasses = getThemeAdaptiveClasses(resolvedTheme);
  ```

- **화면별 치환 내역**:
  1. **`PG-USR-02` (로그인 & 회원가입 위저드)**:
     - 로그인 ID/PW 인풋(`themeClasses.input`, `min-h-[44px]`), 소셜 로그인 3종 버튼(`min-h-[44px]`).
     - 회원가입 위저드 Step 1(약관 동의), Step 2(프로필 사진 업로드 & 실명/별명/전화번호), Step 3(2FA 인증 탭 4종 `tabActive`/`tabInactive` 및 이메일/OAuth 카드), Step 4(가입완료 축하 카드 및 로그인 이동 버튼)를 `themeClasses`로 치환.
  2. **`PG-USR-03` (홈 대시보드 & 7대 PDF 도구 인라인 스튜디오)**:
     - 7대 핵심 도구 퀵 그리드 카드(`themeClasses.card`), 최근 처리 문서 배너(`themeClasses.panel`), 상단 공통 네비게이션 바.
