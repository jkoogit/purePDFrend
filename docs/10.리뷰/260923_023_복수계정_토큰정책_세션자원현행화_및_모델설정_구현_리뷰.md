## 1. 구현 요약

1. **도메인 모델 3대 영역 구축 (`src/aiagent/domain/token-quota/`)**:
   - `VendorAttribute.ts`: 벤더별 불변 정보, 등록 유형(`AI_COLLECTED` vs `SYSTEM_CONFIRMED`), 구독 플랜별 쿼터 규칙(TPM/RPM/RPD, KST 16시 리셋), 에이전트 엔진별 티어 매핑 완비.
   - `UserAiAccount.ts`: 개발자가 소유한 복수 Google 계정(개인 Pro, 공용 Flash) 관리, 계정별 개별 티어 오버라이드 설정, 세션 기본(Default) 활성 계정 스위치 구현.
   - `SessionResourceManager.ts`: 세션 착수 시 우선순위(프롬프트 명시 > 계정 오버라이드 > 사용자 글로벌 선호) 기반 스냅샷 생성, 외부 원장과의 실시간 온디맨드 재동기화(`resyncResource`), 정수 단위 결정론적 무오차 토큰 차감(`recordConsumption`), 차기 세션 착수용 프롬프트 자동 조립(`buildNextSessionPrompt`).

2. **백엔드 REST API 엔드포인트 파이프라인 (`server.ts`)**:
   - `GET /api/agent/system/vendor-attributes`: 벤더 속성 목록 조회 (미존재 시 Google AI Studio 기본값 자동 시딩).
   - `POST /api/agent/system/vendor-attributes`: 벤더 속성 등록 및 플랜 쿼터 갱신.
   - `GET /api/agent/user/ai-accounts`: 사용자 복수 AI 계정 조회.
   - `POST /api/agent/user/ai-accounts`: AI 계정 등록, 수정 및 기본 계정 토글.
   - `POST /api/agent/session/init-quota`: 세션 시작 시 자원 및 티어 정책 확정 바인딩.
   - `POST /api/agent/session/resync-quota`: 작업 진행 중 외부 원장과 세션 자원 온디맨드 재동기화 (KST 16:00 리셋 및 외부 세션 소모량 반영).
   - `POST /api/agent/quota/consume`: AI 산수를 배제하고 백엔드가 정수 단위로 정확히 토큰 및 RPD를 원자적 차감.
   - `GET /api/agent/session/handoff-summary`: 세션 마감 시 차기 세션 인계 프롬프트 자동 제공.

3. **프론트엔드 관제 UI 신설 (`ModelPolicyGovernanceView.tsx`, `SystemSettingsView.tsx`)**:
   - 시스템 관리 > AI 에이전트 관리 그룹 내 **`모델·토큰정책 거버넌스`** 전용 탭 신설.
   - 상단 세션 자원 현황 카드(활성 계정, 잔여 토큰 예산, Tier 1 Pro 잔여 횟수) 및 원클릭 **[🔄 자원 현황 현행화]** 버튼 제공.
   - 3대 설정 영역 탭(1. 벤더별 속성 관리, 2. 사용자 관리, 3. 복수 계정별 모델·에이전트 관리) 완비.
