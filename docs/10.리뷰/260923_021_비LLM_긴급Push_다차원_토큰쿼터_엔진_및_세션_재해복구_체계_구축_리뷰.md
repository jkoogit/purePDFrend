## 📌 1. 개요 및 배경

본 리뷰 문서는 **SESSION-20260922-006**의 두 번째 과제인 **`[02] 비-LLM 긴급 Push, 다차원 토큰 쿼터 엔진 및 세션 재해복구 체계 구축`**의 구현 결과와 아키텍처 정합성을 종합 검증하고 기록하는 기술 리뷰 보고서입니다.

AI 에이전트 개발 환경에서 발생할 수 있는 토큰 소진(429, RPD), 순간 과부하(503, RPM), 15만 토큰 초과 컨텍스트 포화, 에이전트 무응답 행(Hang) 상황에서도 **작업 소스가 절대 유실되지 않는 비-LLM(Non-LLM) 직결 우회로**를 확보하고, **3계층 모델 라우팅 정책(Tier 1 Pro: 250회, Tier 2 Flash: 2,500회)** 및 **무중단 폴백(Graceful Degradation)** 체계를 완비했습니다.

### 🎯 핵심 달성 목표
1. **비-LLM(Non-LLM) 긴급 소스 GitHub Push 엔진 구축**:
   - LLM 에이전트 응답 여부와 무관하게 브라우저 UI에서 직접 호출되어 최종 소스를 원격 `dev` 브랜치에 안전하게 커밋/푸시 (`POST /api/agent/emergency/push`, `EmergencyGitPushEngine`).
2. **다차원 토큰 쿼터 및 모델별 횟수 하이브리드 차감 엔진 (`QuotaDeductionEngine`)**:
   - 토큰 볼륨과 Pro(250회)/Flash(2,500회) 호출 횟수를 동시 추적하고, Pro 소진 시 즉각 Flash로 무중단 라우팅 전환 권고.
3. **세션 재해복구(DR) 및 행(Hang) 상태 판독 도메인 서비스 (`SessionDisasterRecoveryService`)**:
   - 5종 행 원인(일일 쿼터 소진, 순간 부하, 15만 컨텍스트 포화, 10분 지연, 정상) 정밀 판독 및 뱃지 연동.
   - `#세션복구` 인입 시 1건 자동 직결 복구 vs 다건 목록 선택 라우팅 엔진 탑재.
4. **대화 턴 트레이스 파이프라인 자동 차감 직결**:
   - `POST /api/agent/trace/turn` 및 `POST /api/agent/turn/complete` 실행 시 `QuotaDeductionEngine`을 인터셉트하여 매 턴마다 원장 잔액 및 횟수 자동 갱신.
5. **웹 UI 관제 패널 (`EmergencyRecoveryPanel`) 신설**:
   - 원터치 긴급 Push, 세션 스냅샷 백업, 원터치 세션 복구 및 3-Tier 모델 쿼터 현황 프로그레스 바 UI 제공.
6. **거버넌스 헌법 제정 및 개정**:
   - `GEMINI.md`: 3계층 모델 라우팅 및 다차원 쿼터 헌법 제정.
   - `AGENTS.md`: `0-2. 모델 티어링 및 다차원 쿼터 거버넌스`, `0-3. 세션 재해복구(DR) 및 비-LLM 긴급 푸시 규약` 신설.
7. **TDD 단위 테스트 100% 검증 및 무결점 빌드 달성**:

## 🏗️ 2. 변경 상세 내역

### 2.1 도메인 및 서비스 계층 (`src/aiagent/domain/token-quota/`, `src/aiagent/services/`)
* **`EmergencyGitPushEngine.ts`**:
  * Node.js `https` 및 GitHub Git Data API(`/git/blobs`, `/git/trees`, `/git/commits`, `/git/refs`)를 활용하여 컨테이너 내 로컬 변경 파일 전체를 신규 커밋으로 생성하고 대상 브랜치(`dev`)에 직결 Push.
* **`QuotaDeductionEngine.ts`**:
  * `calculateEffectiveTokens(modelId, promptTokens, completionTokens)`: 모델별 승수(Pro 2.5x, Flash 1.0x) 및 응답 토큰 가중치(1.25x) 적용.
  * `executeDeduction(ledger, request)`: 원장에서 유효 토큰 차감, 모델 호출 횟수 증가, 250회 도달 시 `fallbackRecommended: true` 반환.
* **`SessionDisasterRecoveryService.ts`**:
  * `assessHangStatus(params)`: HTTP 코드, 오류 메시지, 누적 토큰(15만), 침묵 시간(10분)을 종합하여 행 유형 및 뱃지 색상/추천 액션 도출.
  * `resolveRecoveryTarget(snapshots, targetId)`: `#세션복구` 명령 인입 시 단일 스냅샷 자동 직결 vs 복수 스냅샷 목록 제시 분기 해석.

### 2.2 백엔드 Express REST API (`server.ts`)
* `POST /api/agent/emergency/push`: 비-LLM 긴급 소스 원격 브랜치 커밋 및 푸시.
* `POST /api/agent/session/snapshot`: 세션 상태 스냅샷 저장 및 PostgreSQL `doc_payload` 보존.
* `GET /api/agent/session/snapshots`: 보존된 세션 스냅샷 목록 조회.
* `POST /api/agent/session/restore`: 타겟팅된 스냅샷 복구 및 후속 세션 추천 프롬프트 반환.
* `GET /api/agent/session/hang-status`: 실시간 세션 행 상태 판독.
* `POST /api/agent/quota/deduct`: 다차원 쿼터 수동 차감 및 감사 로그 기록.
* `GET /api/agent/quota/ledger`: 3-Tier 모델별 잔여 횟수 및 토큰 잔액 조회.
* `POST /api/agent/trace/turn`: 대화 턴 저장 시 `QuotaDeductionEngine` 자동 실행 연동.

### 2.3 프론트엔드 UI 컴포넌트 (`src/aiagent/components/EmergencyRecoveryPanel.tsx`)
* 실시간 행 진단 뱃지 (`정상 작동`, `일일 쿼터 소진`, `순간 부하 지연`, `컨텍스트 포화`, `10분 응답 지연`).
* 3-Tier 쿼터 현황 바:
  * Tier 1 Gemini 1.5 Pro: `250회` 한도 및 잔여 횟수/프로그레스 바 (cyan).
  * Tier 2 Gemini 1.5 Flash: `2,500회` 한도 및 잔여 횟수/프로그레스 바 (emerald).
  * Graceful Degradation: 폴백 권고 상태 뱃지 및 잔여 토큰 표시.
* 3대 액션 버튼: `[🚨 긴급 소스 GitHub Push]`, `[💾 세션 스냅샷 백업]`, `[🔄 #세션복구]`.
* 세션 복구 모달: 스냅샷 선택 및 인계 추천 프롬프트 원클릭 클립보드 복사.
