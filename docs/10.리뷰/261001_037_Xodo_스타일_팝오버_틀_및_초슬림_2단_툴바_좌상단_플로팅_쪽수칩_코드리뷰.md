## 1. 개요 및 목적 (Context & Purpose)

본 태스크는 사용자님께서 제공해 주신 **Xodo 모바일/태블릿 실전 앱 화면 분석 자료(슬라이드 43종 및 상세 스타일 팝오버 8종)**를 바탕으로, 브라우저 및 PWA 환경에서 독서 몰입감과 전문 필기 사용성을 극대화하기 위한 **UI 뼈대(Framework) 전면 개편**을 목적으로 수행되었습니다.

기존 purePDFrend 뷰어의 한계였던 4단 중첩 툴바로 인한 화면 가림 현상을 해소하고, 태블릿 전문 뷰어 표준인 **초슬림 2단 통폐합 툴바, 플로팅 쪽수 칩(157/504), Xodo 스타일(도구 상세속성) 팝오버 틀, 밑줄 주석 선택 시 상황별 액션 팝오버(3번째 아이콘 형태전환)**를 성공적으로 구현하였습니다.

## 2. 주요 구현 및 개선 내역 (Key Implementations)

### 2.1 초슬림 2단 툴바(Top 1단/2단) 통폐합 레이아웃
* **Top 1단 (글로벌 액션 헤더)**:
  - `[← 서재 목록]` 복귀 버튼 (독서 진행률 실시간 역동기화 지원)
  - `[주석 달기 ∨]` 모드 스위처 드롭다운 (클릭 시 6대 모드 전환 메뉴 노출)
  - `[도서명]` (ISO 32000-2 표준 가이드북 및 아카이빙 지침서)
  - `[🔍 검색]` + `[📑 3탭 목차/북마크 패널]` + `[◫/⬒ 배치 전환]` + `[⚙ 순서설정]`
* **Top 2단 (도구 툴바)**:
  - 현재 선택된 모드에 속한 도구 아이콘 1줄 가로 슬라이더
  - **`[🎨 스타일 팝오버 버튼]`** (현재 색상 미니 원형 칩 내장)
  - `[↶ 실행취소(Undo)]` / `[↷ 다시실행(Redo)]`
  - 배율 조절 컨트롤 `[- 100% +]`
* **성과**: 상단 점유 높이를 **88px 이내**로 압축하여 본문 캔버스 면적을 90% 이상으로 확장.

### 2.2 Xodo [스타일(도구 상세속성) 팝오버 틀] 컴포넌트 (`ToolStylePopover.tsx`)
* **스타일 메인 뷰**:
  - `색상`: 현재 색상 원형 칩 + Chevron (클릭 시 2단계 서브 화면으로 부드럽게 전이)
  - `획 (두께)`: 0.5pt ~ 15pt 슬라이더 및 수치 실시간 표시
  - `불투명도`: 10% ~ 100% 슬라이더 및 % 표시
  - `4대 프리셋 칩`: 자주 쓰는 `[ A ][ A ][ A ][ A ]` 콤보 슬롯 원클릭 즉시 적용
* **색상 서브 뷰**:
  - `24색 바둑판 팔레트` 탭 (원클릭 체크 피드백)
  - `HEX 직접입력` 탭 (RGB 코드 직접 지정)

### 2.3 캔버스 좌상단 플로팅 쪽수 칩 (`157 / 800`)
* 본문 좌측 상단에 반투명 다크 캡슐(`bg-black/75 backdrop-blur-md border border-white/20`)로 쪽수 배지 배치.
* 배지 탭 시 **직관적인 슬라이더 + 직접 쪽번호 입력 점프 팝오버** 노출.

### 2.4 밑줄/주석 클릭 시 상황별 액션 팝오버 (`AnnotationActionPopover.tsx`)
* 밑줄 친 텍스트(`"코드를 바로 실행해볼 수도 있습니다."`) 클릭 시:
  - 양 끝에 블루 터치 핸들러(`● ─── ●`) 시각적 피드백 제공.
  - 상단 15px 위에 다크 플로팅 미니바 노출:
    - **1. 팔레트(🎨)**: 8색 프리셋 바둑판 노출 ➔ 밑줄 색상 원클릭 실시간 변경.
    - **2. 메모(💬)**: 주석 메모 입력창 즉시 노출.
    - **3. [핵심] 형태전환(🔤)**: 3번째 아이콘 터치 시 **`[형광펜 | 취소선 | 물결선 | 밑줄]`** 2차 미니 팝업 노출 ➔ 주석을 지우지 않고도 실시간 벡터 렌더링 형태 상호 전환.
    - **4. 삭제(🗑️)**: 해당 주석 원클릭 삭제.
    - **5. 복사(📋)**: 텍스트 클립보드 복사.
