## 1. 개요 및 변경 배경

본 작업은 엔터프라이즈 PDF 뷰어(PG-USR-06)의 사용자 피드백을 수렴하여 다음 세 가지 핵심 영역을 완결한 작업입니다:
1. **목차 탭 복구 및 'toc' 영문 문자 배제**:
   - 기존 'toc' 문자로 인해 발생하던 탭 간 불일치를 해소하기 위해 영문 'TOC'/'(TOC)'를 완전 배제하고, `북마크` / `목차` / `주석` 3대 탭의 폰트, 여백, 언더라인 및 카운트 배지 스타일을 100% 일치화하였습니다.
2. **도구 툴바 레이아웃 정돈 (검색창 좌측, 선택목록·도구 우측 정렬)**:
   - 주석 탭에 비해 요소 수가 적은 북마크 탭과 목차 탭에서 도구들이 중앙에 붕 떠 보이던 현상을 해결하기 위해, 모든 탭 공통으로 **검색 필드는 좌측(`flex-1 max-w-xs`)**, **선택 목록 및 조작 도구들은 우측(`ml-auto flex items-center gap-1.5 justify-end`)**에 정렬하도록 표준화하였습니다.
3. **주석 선택목록 레이어 팝업 및 '전체' 토글 로직**:
   - 주석 본문 목록의 1열 단일행 레이아웃을 보존하면서, 팝업 트리거 버튼 클릭 시 펼쳐지는 레이어 팝업 카드 내에 개별 체크박스(자유펜, 도형, 텍스트, 마크업)를 제공하였습니다.
   - '전체' 체크박스 클릭 시 모든 하위 항목 일괄 해제, 재클릭 시 전체 재선택 토글 규칙을 완벽 적용하였습니다.
4. **OCR 변경건 위/아래(▲/▼) 순차 탐색 및 즉시 현행화**:
   - OCR 변경건 감지 시 나타나는 배너에 `▲ 위` / `▼ 아래` 버튼을 통해 변경된 주석으로 즉시 이동하고 캔버스/목록 동시 포커싱 및 스크롤을 수행합니다.
   - `⚡ 선택건 즉시 현행화` 버튼과 `탐색 시 즉시 현행화` 자동 토글 옵션을 지원하여 원터치로 OCR 결과를 즉시 반영할 수 있도록 개선하였습니다.

### 2.4 OCR 변경건 탐색 및 즉시 현행화
```tsx
const handleNavigateOcr = (direction: 'prev' | 'next') => {
  if (ocrUpdatedAnnots.length === 0) return;
  const newIdx = direction === 'prev'
    ? (currentOcrFocusIdx - 1 + ocrUpdatedAnnots.length) % ocrUpdatedAnnots.length
    : (currentOcrFocusIdx + 1) % ocrUpdatedAnnots.length;
  setCurrentOcrFocusIdx(newIdx);
  const targetAnn = ocrUpdatedAnnots[newIdx];
  if (targetAnn) {
    focusAnnotationById(targetAnn.id, targetAnn.page);
    if (isAutoSyncOnNavigate) {
      handleSyncSingleAnnotationOcr(targetAnn.id, targetAnn.title, false);
    }
  }
};
```
- 위/아래 순환 탐색 시 해당 주석 페이지로 자동 이동, 캔버스 포커스 및 주석 행 스크롤 애니메이션.
- `isAutoSyncOnNavigate` 토글 활성화 시 탐색 즉시 해당 건 자동 동기화 처리.
