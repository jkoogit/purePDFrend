## 1. 문제 해결 배경 및 UX 개선 철학

### 1-1. 상단 탑 레이어(Header) 극단적 미니멀리즘 확립
- **프로필 아이콘 단독 노출**: 헤더 바에는 텍스트(계정 ID, 역할 등)를 노출하지 않고, 미니멀하고 세련된 원형 프로필 아바타 아이콘(온라인 녹색 인디케이터 배지 포함)만 노출합니다.
- **뷰어 열기 아이콘 복구**: 직관적인 기존 `📖 뷰어 열기` 버튼 형태로 즉시 복구하였습니다.
- **헤더 내 과도한 서비스 버튼 제거**: 탑레이어 바에 노출되던 관리자/에이전트 버튼을 헤더에서 완전히 걷어내어 시각적 잡음을 원천 차단하였습니다.

### 1-2. 프로필 레이어(Profile Layer) 5단계 정밀 구조화
프로필 아이콘 클릭 시 오픈되는 전용 레이어 팝오버를 다음의 5단계 섹션으로 완벽히 정렬하였습니다:

1. **상단 프로필 & 5대 인증 아이콘 (Focus Mode 반영)**:
   - 고해상도 아바타 이미지
   - 계정 ID (`@jkok2j2m`) 및 이름 (`정진국`), 권한 배지 (`ROLE_SYSADMIN`)
   - **텍스트 배제, 인증 언급 5대 아이콘 및 정밀 여백 배치**:
     - ① Google 소셜 계정 OAuth 2.0 인증 아이콘
     - ② GitHub 워크스페이스 & Git Data API 연동 인증 아이콘
     - ③ 2단계 인증 (`2FA OTP`) 하드웨어/소프트웨어 인증 아이콘
     - ④ 공식 이메일 소유권 검증 아이콘 (`MailCheck`)
     - ⑤ 시스템 관리자 루트 보안 토큰 (`.env / JWT`) 인증 아이콘 (`Key`)
2. **영역 절약형 고효율 기능: 스토리지 & 일일 쿼터 게이지 (기회비용 최적화)**:
   - 세로 24px의 극소 면적만을 활용하여, 사용자가 가장 필요로 하는 클라우드 저장소 사용량(`1.4 GB / 5.0 GB - 28%`) 및 오늘의 OCR 잔여 쿼터(`42 / 50 회`)를 인라인 프로그레스 바로 제공합니다.
3. **최근 읽은 문서 vs 즐겨찾기 문서 4권 가로 휠 스크롤 슬라이더**:
   - `최근 열람 (4)`과 `즐겨찾기 (4)` 탭 전환 지원.
   - 마우스 휠 이벤트(`onWheel`)를 통해 좌우 가로 스크롤로 매끄럽게 탐색 가능.
   - 각 문서별 태그, 페이지 수, 진행률(%), 1클릭 뷰어 바로 열기 지원.
4. **계정 세부 정보 및 보안 관리**:
   - 이메일 주소 (`jkok2j2m@gmail.com`) 및 가입 정보 (`2024.03.15 · Pro 플랜`)
   - 비밀번호 변경 바로가기 및 2단계 인증 상태 표시.
5. **하단 전용 액션 바 (권한 연동)**:
   - **권한 보유 시에만 노출**: `🤖` 에이전트 서비스, `🛠` 관리자 서비스 아이콘
   - **공통 제어 버튼**: `⚙️` 정밀 환경설정 (`PG-USR-09`), `🚪` 로그아웃 (`PG-USR-02`)
