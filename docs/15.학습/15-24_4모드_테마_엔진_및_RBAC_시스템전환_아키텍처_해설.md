## 2. 4모드 테마 시스템 아키텍처 (4-Mode Theme Engine)

### 2.1 다중 모드 지원 동기 및 여명(Dawn) 테마의 가치
- **기존 2모드(Light/Dark)의 한계**:
  단순 흑백 전환은 심야에 PDF 문서를 장시간 검토하거나 OCR 바운딩 박스를 정밀 교정하는 사용자에게 시각적 피로감을 유발합니다.
- **여명(Dawn - Midnight Blue) 모드 도입**:
  - 배경: 딥 미드나잇 네이비 (`#070e22`)
  - 패널/카드: 인디고 네이비 (`#0e1a38`, `#132247`)
  - 텍스트/포인트: 스카이 블루/시안 (`#38bdf8`, `#f0f6ff`)
  - 어두운 환경에서도 푸른빛의 깊이감과 가독성을 극대화하여 집중도를 보장합니다.
- **시스템설정(System) 모드**:
  `window.matchMedia('(prefers-color-scheme: dark)')` 이벤트 리스너를 바인딩하여 사용자가 OS 레벨에서 테마를 변경할 때 실시간으로 앱 테마가 무순단으로 동기화됩니다.

### 2.2 구현 코드 패턴 (`src/styles/tokens.ts`)

```typescript
export function resolveThemeMode(mode: ThemeMode): ResolvedTheme {
  if (mode === 'system') {
    if (typeof window !== 'undefined' && window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) {
      return 'dark';
    }
    return 'light';
  }
  return mode;
}

export function applyThemeToDocument(mode: ThemeMode): ResolvedTheme {
  const resolved = resolveThemeMode(mode);
  if (typeof document !== 'undefined') {
    const root = document.documentElement;
    root.classList.remove('light', 'dark', 'dawn', 'theme-light', 'theme-dark', 'theme-dawn');
    root.classList.add(resolved, `theme-${resolved}`);
    root.setAttribute('data-theme', resolved);
    root.setAttribute('data-theme-mode', mode);
  }
  return resolved;
}
```

## 3. 역할 기반 3대 시스템 전환 (RBAC System Switching)

### 3.1 3계층 도메인 격리
1. **PDF 비즈니스 서비스 (`service`)**:
   - `PurePdfServicePortal`
   - 일반 사용자, 뷰어, 문서 변환기, OCR 교정기 대상의 프로덕션 B2C 서비스
2. **서비스 설정 (`settings`)**:
   - `WireframeStudio` 및 25개 와이어프레임 프로토타입
   - 서비스 기획자, UI/UX 디자이너, 운영자 대상의 설정 스튜디오
3. **에이전트 관리 (`harness`)**:
   - `WorkGraphViewer`, `TaskInfoManager`, `AgentUsageViewer` 등
   - 시스템 관리자 및 개발자 대상의 AI 거버넌스 및 메타 원장 관제실

### 3.2 역할 기반 접근 제어 매트릭스

```typescript
export const SYSTEM_DOMAINS: SystemDomainConfig[] = [
  {
    id: 'service',
    label: 'PDF 서비스',
    requiredRole: ['ROLE_USER', 'ROLE_OPERATOR', 'ROLE_ADMIN', 'ROLE_SUPER_ADMIN'],
  },
  {
    id: 'settings',
    label: '서비스설정',
    requiredRole: ['ROLE_OPERATOR', 'ROLE_ADMIN', 'ROLE_SUPER_ADMIN'],
  },
  {
    id: 'harness',
    label: '에이전트관리',
    requiredRole: ['ROLE_ADMIN', 'ROLE_SUPER_ADMIN'],
  },
];
```

### 3.3 역할 시뮬레이터 (Role Simulator) 패턴
- 개발 및 시연 환경에서 실제 로그아웃이나 DB 수정 없이 헤더 팝오버를 통해 `일반사용자`, `서비스설정자`, `마스터관리자` 권한을 즉시 전환하여 각 권한별 가시성과 제한 모달 동작을 원클릭으로 검증할 수 있습니다.

## 4. 반응형 및 44px 터치 가드레일

- 데스크톱과 모바일 햄버거 드로어 양쪽 모두에서 4모드 테마 버튼과 3대 시스템 스위처 버튼은 `min-h-[44px]` 및 `min-w-[44px]` 최소 터치 영역을 100% 준수합니다.
- Zero-pill 규율에 따라 사각 버튼 모서리는 8px~12px (`rounded-lg`, `rounded-xl`)로 일관성 있게 구성되었습니다.
