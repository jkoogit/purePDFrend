## 2. 핵심 구현 아키텍처 및 패턴

### 1) 복합 기능키 조합 파서 & 빌더 (Compound Shortcut Parser & Builder)
기존 단일 문자(Key) 입력 방식은 브라우저 기본 단축키와의 충돌이나 단축키 부족 문제를 야기합니다.
이를 해결하기 위해 Modifier Key(`Ctrl`, `Shift`, `Alt`)를 독립적인 불리언 상태로 분리하고, 조합 문자열을 동적으로 생성하는 양방향 변환기를 적용하였습니다:

```typescript
function parseShortcut(sc: string) {
  const parts = (sc || '').split('+').map((p) => p.trim());
  const hasCtrl = parts.some((p) => /^(ctrl|control)$/i.test(p));
  const hasShift = parts.some((p) => /^shift$/i.test(p));
  const hasAlt = parts.some((p) => /^alt$/i.test(p));
  const mainKey = parts.filter((p) => !/^(ctrl|control|shift|alt)$/i.test(p)).pop() || '';
  return { hasCtrl, hasShift, hasAlt, mainKey };
}

function buildShortcut(hasCtrl: boolean, hasShift: boolean, hasAlt: boolean, mainKey: string) {
  const parts: string[] = [];
  if (hasCtrl) parts.push('Ctrl');
  if (hasShift) parts.push('Shift');
  if (hasAlt) parts.push('Alt');
  const cleanKey = (mainKey || '').trim().toUpperCase();
  if (cleanKey) parts.push(cleanKey);
  return parts.join(' + ') || cleanKey;
}
```

이 패턴을 통해 사용자는 체크박스를 클릭하거나 메인 키를 입력할 때 실시간으로 `Ctrl + Shift + P` 형식의 일관된 단축키 토큰을 획득하게 됩니다.

### 2) 1-글꼴 패밀리 다중 파일(1:N) 첨부 관리 패턴
웹폰트는 통상 단일 파일이 아니라 Regular, Bold, SemiBold, ExtraBold 등 복수의 굵기(Weight)와 확장자(`.woff2`, `.ttf`)로 구성됩니다.
- HTML `<input type="file" multiple>`을 활용하여 1회에 다수 파일을 선택할 수 있도록 구현.
- 업로드된 파일명 배열(`fileNames: string[]`)을 독립 칩(Chip) 컴포넌트로 시각화하고 `✕` 버튼으로 개별 제거 지원.
- 카드 뷰에서 `첨부 글꼴 파일 (N개)`를 표시하여 운영 가시성을 극대화.
