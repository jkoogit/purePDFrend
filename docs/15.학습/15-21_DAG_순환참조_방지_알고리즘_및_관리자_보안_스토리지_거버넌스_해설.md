## 2. DAG 순환참조 방지 알고리즘 (Cycle Detection)

### 2.1 문제 정의
화면 프로그램 계층 트리에서 프로그램 A의 부모로 프로그램 B를 지정하고, 프로그램 B의 부모로 프로그램 A(또는 A의 하위 자식)를 지정하면 무한 루프가 발생하는 순환 종속성(Cycle)이 발생합니다.

### 2.2 사이클 검출 알고리즘
```typescript
function isDescendantOf(
  nodeId: string,
  targetAncestorId: string,
  programs: Map<string, string | null> // child -> parent
): boolean {
  let currentParent = programs.get(nodeId);
  while (currentParent) {
    if (currentParent === targetAncestorId) {
      return true; // 조상 노드 발견 -> 순환 참조 발생!
    }
    currentParent = programs.get(currentParent);
  }
  return false;
}
```

이 검증을 통해 사용자가 부모 노드를 변경할 때 실시간으로 순환 여부를 감지하고 저장을 차단합니다.

## 3. 관리자 개인정보 불변 원칙 (Privacy Immutability)
관리자 권한이라도 사용자의 비밀번호 평문, 주민번호, 개인 전화번호는 수정할 수 없습니다. 이는 내부자 위협(Insider Threat) 방지 및 개인정보보호법 컴플라이언스를 위한 필수 가드레일입니다. 비밀번호 분실 시 관리자는 '임의 변경'이 아닌 '비밀번호 재설정 일회용 링크 발송'만 수행할 수 있습니다.
