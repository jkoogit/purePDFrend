## 2. 주요 API 엔드포인트 사양

### 2.1 대화 턴 저장 및 텔레메트리 (`POST /api/agent/trace/turn`)
- **Request**:
  ```json
  {
    "session_id": "SESSION-xxx",
    "task_id": "TASK-xxx",
    "loop_id": "LOOP-xxx",
    "step_index": 3,
    "user_prompt": "...",
    "agent_response": "..."
  }
  ```
- **Response**:
  ```json
  {
    "success": true,
    "traceId": "TR-xxx",
    "telemetry": {
      "burnout_risk_index": 24,
      "burst_score": 1.05,
      "burn_rate_velocity": 2400,
      "loop_safety_margin": 6.8,
      "risk_level": "SAFE"
    }
  }
  ```

### 2.2 세션 스코어카드 산출 (`POST /api/agent/telemetry/scorecard`)
- **Request**: `{ "sessionId": "SESSION-xxx" }`
- **Response**: `{ "success": true, "scorecard": { "mape_percent": 7.4, "calibration_weight_alpha": 1.092, ... } }`

### 2.3 세션 인계 도시에 생성 (`POST /api/agent/session/dossier`)
- **Request**: `{ "sessionId": "SESSION-xxx", "reason": "SUSPENDED_QUOTA" }`
- **Response**: `{ "success": true, "dossier": { "handoff_token": "HANDOFF-xxx", "resume_prompt": "..." } }`
