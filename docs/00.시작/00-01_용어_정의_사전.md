# 00. 서비스 체계 용어 정의 & 커뮤니케이션

## 1. 기본 서비스(플랫폼/하네스) vs 대상 서비스(PDF 스튜디오)

| 구분 | 영역 | 주요 역할 및 구성 요소 |
| :--- | :--- | :--- |
| **기본 서비스 (Base Platform)** | 하네스/바이브코딩 엔진 | 세션(Session) - 태스크(Task) - 루프(Loop) 3계층 거버넌스, 개발DB(`purepdfrend_dev`), 문서 동기화, 감사 로그 |
| **대상 서비스 (Target Domain)** | purePDFrend PDF 스튜디오 | 스캔 도서 페이지 결합, 800쪽 대용량 가상화, 고정밀 OCR 교정, 목차(TOC), PDF 표준 주석, 툼스톤 동기화 |

---

## 2. 하네스(Harness) 3계층 핵심 용어

- **세션 (Session)**: 전체 개발 작업의 최상위 단위 (예: `SESSION-20260917-001`). 이전 세션 인계 및 최종 회고를 총괄.
- **태스크 (Task)**: 특정 기능이나 아키텍처 개편을 담당하는 Git 브랜치 단위 작업 (예: `TASK-20260917-001`, `task/작업명_에이전트명`).
- **루프 (Loop)**: 태스크 내부에서 실행되는 원자적 반복 작업 단위 (WorkItem, TDD, 리팩터링, UI 컴포넌트 단위).
- **상태 전이 5단계**: `시작(START) -> 처리(IN_PROGRESS) -> 정리(CLEANUP) -> 승급(PROMOTE) -> 종료(DONE)`.

---

## 3. PDF 스튜디오 핵심 도메인 용어

- **800쪽 대용량 가상화 (Large-scale Virtualization)**: DOM 노드 폭증으로 인한 브라우저 크래시를 방지하기 위해 뷰포트에 표시되는 2~4페이지만 렌더링하고 나머지는 가상 스크롤 높이로 유지하는 메모리 가드(38MB 유지) 기술.
- **2-Way BBox 동기화 (Dual Bounding Box Sync)**: 스캔 원본 이미지의 텍스트 영역 박스와 우측 텍스트 에디터 간의 1:1 양방향 하이라이트 및 수정 동기화 메커니즘.
- **TOC 아웃라인 (Table of Contents Outlines)**: PDF 표준 사양(ISO 32000)의 북마크 계층 구조(부, 장, 절, 페이지 매핑)를 생성·편집하는 기능.
- **툼스톤 주석 동기화 (Tombstone Synchronization)**: 삭제된 주석을 물리 삭제하지 않고 `isDeleted: true` 상태로 관리하여 오프라인 충돌을 방지하는 동기화 기법.
