# 00. 서비스 체계 용어 정의 & 커뮤니케이션 (Terminology Glossary)

본 문서는 **purePDFrend** 엔터프라이즈 PDF 제작, OCR 교정 및 하네스 개발 플랫폼의 공식 용어 정의 기준서입니다.

---

## 1. 기본 서비스(플랫폼/하네스) vs 대상 서비스(PDF 스튜디오)

| 구분 | 영역 | 주요 역할 및 구성 요소 |
| :--- | :--- | :--- |
| **기본 서비스 (Base Platform)** | 하네스/바이브코딩 엔진 | 세션(Session) - 태스크(Task) - 루프(Loop) 3계층 거버넌스, 개발DB(`purepdfrend_dev`), 문서 동기화, 감사 로그 |
| **대상 서비스 (Target Domain)** | purePDFrend PDF 스튜디오 | 스캔 도서 페이지 결합, 800쪽 대용량 가상화, 고정밀 OCR 교정, 목차(TOC), PDF 표준 주석, 툼스톤 동기화 |

---

## 2. 하네스(Harness) 3계층 핵심 용어

- **세션 (Session)**: 전체 개발 작업의 최상위 단위 (예: `SESSION-20260917-001`). 이전 세션 인계 및 최종 회고를 총괄.
- **태스크 (Task)**: 특정 기능이나 아키텍처 개편을 담당하는 Git 브랜치 단위 작업 (예: `TASK-20260917-001`, `task/작업명_에이전트명`).
- **루프 (Loop)**: 태스크 내부에서 실행되는 원자적 반복 작업 단위 (WorkItem, TDD, 리팩터링, UI 컴포넌트 단위).
- **작업 그래프 (Work Graph / DAG)**: 세션, 태스크, 루프 간의 선후 관계, 의존성(`depends_on`) 및 실행 흐름을 시각화한 비순환 유향 그래프.

---

## 3. purePDFrend 비즈니스 도메인 핵심 용어

- **2-Way 대조 OCR 교정**: 원본 스캔 이미지 위에 바운딩 박스(Bounding Box)를 오버레이하고, 우측 텍스트 에디터와 1:1 양방향 포커스를 연결하여 오타 및 영역을 보정하는 UX 패턴.
- **800쪽 가상화 뷰어 (Virtualized Viewer)**: 대용량 문서를 로딩할 때 전체 페이지 DOM 생성을 차단하고, 화면에 보이는 뷰포트 영역 페이지만 메모리에 온디맨드로 유지하는 아키텍처.
- **페이지 단위 영속화 (Page-Level Persistence)**: 편집된 페이지의 이미지, OCR 박스, 회전 각도, 주석을 IndexedDB에 즉시 분할 저장하여 동시 작업 충돌과 메모리 누수를 원천 차단하는 기법.
- **툼스톤 주석 관리 (Tombstone Annotation)**: 주석 삭제 시 물리적으로 즉시 삭제하지 않고 `isDeleted: true` 툼스톤 마커를 부여하여, 부분 추출 및 다른 환경과의 병합 시 삭제 상태가 유실되지 않도록 보장하는 동기화 프로토콜.
- **PDF 표준 Outlines (TOC)**: PDF 스펙의 계층형 북마크 트리 딕셔너리(`\Outlines`, `\First`, `\Last`, `\Dest`) 구조.
