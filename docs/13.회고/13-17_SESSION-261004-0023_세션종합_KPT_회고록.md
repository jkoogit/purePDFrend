2. **Full-Text 서식 보존 및 Markdown 뷰어 시각화 무결성**:

   - 뷰어를 가리던 불필요한 슬라이드 화살표를 과감히 제거하고 네이티브 스크롤과 전체화면/몰입형 독서 모드를 제공함으로써 PDF 전용 스튜디오로서의 전문성을 완성함.

1. **토큰 쿼터 소진 시 컨텍스트 단절 현상**:
   - 토큰 한도 도달 시 대화가 중단되면서 마지막 턴의 상태가 로컬에만 머물고 원격 DB 반영이 지연될 위험이 존재했음.

2. **필드명 파편화로 인한 혼선**:
   - 로컬 스토어의 `prompt_text`와 백엔드 DB의 `user_prompt` 간의 네이밍 차이로 인해 초기 동기화 시 데이터 유실이 발생했던 점.
