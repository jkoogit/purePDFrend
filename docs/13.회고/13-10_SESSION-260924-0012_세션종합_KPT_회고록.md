## 🎯 3. KPT 상세 회고

### 🟢 Keep (지속 유지할 점)
1. **Command/Memento 패턴 기반 무제한 히스토리 & 소프트 삭제 분리**:
   - 페이지 레이아웃 및 OCR BBox 수정 시 실시간 변경과 실행취소/다시실행의 무결성을 분리 보장하여 사용자 작업 실수를 100% 안전하게 보호.
2. **In-Memory Write-Through 캐시 & React 18 불변 참조 안정성**:
   - `PdfConfigManager`를 싱글톤 인메모리 캐시(0ms Read)와 `localStorage` 영속화로 이원화하고, `useSyncExternalStore` 캐싱으로 React 무한 렌더링 루프를 원천 방어.
3. **SHA-256 상태 지문 기반 DR 스냅샷 디둡 & 2계층 복구**:
   - 동일 상태에 대한 불필요한 스냅샷 파일 양산을 방지하고, 10건 초과분은 Cold Storage로 격리하여 스토어 청결성과 영구 복구성 동시 확보.
4. **전역 유니코드 NFC 정규화 및 UTF-8 가드레일**:
   - macOS NFD 자모 분리와 Windows 파일명 깨짐을 사전에 차단하는 전역 가드레일을 도입하여 다국어 안정성 극대화.
5. **대화 턴 21건 전수 영속화 및 4대 브랜치 100% SHA 동기화**:
   - 요청-응답 전문과 서식을 빠짐없이 DB 및 로컬 스토어에 보존하고, `dev` = `stg` = `main` = `task` 커밋 SHA를 완벽 동기화.

### 🔴 Problem (발견된 문제점 및 개선 대상)
1. **대용량(100쪽+) PDF 내보내기 시 메인 스레드 연산 부하**:
   - `pdf-lib`의 텍스트 레이어 합성 연산이 메인 스레드에서 실행되므로, 초대용량 도서 합성 시 UI 반응성이 일시 저하될 가능성 존재.
2. **다중 페이지 OCR 배치 처리 시 백그라운드 워커 큐 분리 필요**:
   - 수십 페이지에 걸친 OCR 인식 작업을 브라우저 백그라운드 Web Worker로 오프로딩하여 UI 차단(Blocking)을 완벽 배제할 필요성.
