## 2. 5대 핵심 도메인 파이프라인

1. **시나리오 1: 800쪽 대용량 스캔 PDF 뷰어 (Virtualization)**
   - 대용량 도서 스캔 파일(800쪽 이상, 수백 MB) 로딩 시 메모리 누수를 원천 차단하기 위해 화면 뷰포트 내 상하 2~4페이지만 동적 렌더링.
   - 브라우저 탭 메모리를 항상 38MB 수준으로 일정하게 유지.

2. **시나리오 2: 2-Way BBox 대조 OCR 에디터**
   - 캔버스 위의 감지된 바운딩 박스를 클릭하면 텍스트 에디터의 해당 줄로 즉시 포커스 이동.
   - 텍스트 수정 시 실시간으로 바운딩 박스의 텍스트 메타데이터가 1:1 동기화.

3. **시나리오 3: 계층형 목차(TOC) 트리 에디터**
   - 부(Part) > 장(Chapter) > 절(Section) 형태의 계층 구조를 직관적으로 들여쓰기/내어쓰기/재정렬.
   - 최종 PDF 표준의 북마크(Outlines) 스펙으로 직접 컴파일.

4. **시나리오 4: PDF 표준 주석 및 툼스톤 동기화**
   - 하이라이트, 텍스트 메모, 취소선 등의 주석을 표준 규격으로 지원.
   - 삭제 요청 시 `isDeleted: true` 툼스톤 처리하여 다중 환경 동기화 충돌 방지.

5. **시나리오 5: 최종 PDF 표준 컴파일러**
   - 원본 고해상도 스캔 이미지 레이어 + 투명 텍스트 레이어(검색 가능) + TOC 아웃라인 + 주석을 병합하여 표준 PDF로 생성.
