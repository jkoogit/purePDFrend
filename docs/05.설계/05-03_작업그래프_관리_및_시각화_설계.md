## 1. 다중 계층 동시 표시 (View Modes)
작업그래프(Work Graph)는 계층별 독립 렌더링뿐 아니라 다중 선택을 통한 **동시 표시**를 기본 지원합니다.
- `[x] 세션 카드`: 전체 세션의 진행률, 목표, 상태 표시
- `[x] 태스크 카드`: 세션 하위 태스크, 담당 Git 브랜치, 상태 표시
- `[x] 루프 카드`: 태스크 내부의 원자적 루프 단계, 진행 타임라인 표시

사용자는 3개 계층 체크박스를 모두 활성화하여 전체 트리를 한 화면에서 조망할 수 있습니다.

---

## 2. 카드 정보 간격 설정 규정 (Spacing Presets)
화면 밀도와 사용자 선호도에 따라 4단계 간격 프리셋을 지원합니다:
1. **좁게 (Compact, 24px)**: 많은 수의 노드를 한눈에 파악할 때 유용
2. **기본 (Normal, 48px)**: 표준 가독성 모드
3. **넓게 (Wide, 72px)**: 노드별 세부 설명 및 페이로드를 여유 있게 확인할 때 유용
4. **사용자 설정 (Custom Slider)**: 16px ~ 120px 범위 내에서 슬라이더로 픽셀 단위 미세 조절
