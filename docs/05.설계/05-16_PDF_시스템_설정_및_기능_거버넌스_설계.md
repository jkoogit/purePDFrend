## 1. 개요 및 목적

본 문서는 purePDFrend 스튜디오의 전 도메인(가상 뷰포트, 이미지 전처리, 다국어 OCR, 페이지 레이아웃 편집기, Searchable PDF 내보내기, 2-Way OCR 교정기)에서 사용되는 모든 기능적 플래그와 동작 모드를 중앙 집중식으로 관리하는 **In-Memory Write-Through PDF 시스템 설정 아키텍처**를 정의합니다.

### 1.1 핵심 설계 목표
1. **0ms 무지연 Fast Read**: 기능 실행 시마다 I/O(스토리지/DB) 조회를 배제하고 메모리 상주 단일 인스턴스(RAM Cache)에서 즉시 읽기 처리.
2. **라이트스루 캐시 (Write-Through Persistence)**: 설정 변경 시 메모리 갱신 즉시 수행 후 스토리지(`localStorage`) 동기/비동기 안전 영속화.
3. **옵저버 및 React 18 반응형 연동**: `useSyncExternalStore` 및 옵저버 패턴을 통해 설정 변경 즉시 전 UI 컴포넌트 0ms 리액티브 동기화.
4. **논리적 모순 방어**: 상충하는 옵션 조합(예: LiveSync vs 뷰어 Undo 스택 폭주, 디버그 텍스트 레이어 vs 정식 배포 PDF)을 시스템 차원에서 자동 격리 및 안전 제어.
5. **원클릭 프리셋 프로파일**: 사용 목적에 따른 원클릭 프리셋(정밀 교정, 초고속 처리, 대용량 도서 메모리 세이프) 지원.

## 3. 6대 도메인 15개 설정 스키마 명세

```typescript
export interface PdfSystemConfig {
  // ① [OCR 교정기 도메인]
  liveSyncCorrection: boolean;        // true: 편집 즉시 뷰어 반영, false: [저장] 클릭 시 반영
  autoScrollSync: boolean;            // 2-Way 캔버스 ↔ 에디터 포커스 자동 스크롤
  enableBBoxSnap: boolean;            // BBox 드래그/리사이즈 시 4px 그리드 스냅 (Shift 누르면 해제)
  showConfidenceBadges: boolean;      // 80% 미만 저신뢰도 단어 경고 배지 표시
  enableKeyboardShortcuts: boolean;   // Ctrl+Z/Y, Del, M, S 단축키 활성화
  highContrastBBox: boolean;          // 고대비 네온 BBox 포커스 링 모드

  // ② [페이지 레이아웃 도메인]
  autoCleanOnSave: boolean;           // 저장/내보내기 시 소프트 삭제 페이지 영구 클린징
  maxHistoryDepth: number;            // 실행취소 최대 스택 수 (0: 무제한)

  // ③ [PDF 내보내기 도메인]
  defaultExportFont: string;          // 기본 임베딩 폰트 ('Helvetica' | 'Noto Sans KR' | 'Times' | 'Courier')
  exportDebugTextLayer: boolean;      // 디버그용 반투명 붉은 텍스트 레이어 생성 여부
  includeSoftDeletedInExport: boolean;// 소프트 삭제된 페이지 포함 여부 (기본 false)

  // ④ [뷰어 & 메모리 도메인]
  lruCacheSize: number;               // 가상 스크롤 메모리가드 LRU 캐시 크기 (기본 10)
  renderResolutionDpi: number;        // 캔버스 렌더링 배율 (1.0x, 1.5x, 2.0x)

  // ⑤ [이미지 전처리 도메인]
  autoBinarization: boolean;          // 전처리 이진화(Otsu) 자동 적용
  autoDeskew: boolean;                // 기울기 자동 보정 활성화

  // ⑥ [OCR 엔진 도메인]
  defaultOcrEngine: string;           // 기본 엔진 ('WASM' | 'Gemini' | 'PaddleOCR')
  confidenceThreshold: number;        // 저신뢰도 판정 임계값 (0.0 ~ 1.0, 기본 0.80)
}
```

## 4. 원클릭 프리셋 프로파일 (Preset Profiles) 전략

사용자가 개별 설정을 일일이 조정하지 않고 작업 목적에 맞추어 원클릭으로 일괄 전환할 수 있도록 3대 프리셋을 제공합니다.

| 프리셋 ID | 명칭 | 핵심 타겟 및 특징 | 주요 플래그 조합 |
| :--- | :--- | :--- | :--- |
| `precision` | **🎯 정밀 교정 모드** | 교정 정확도 및 시각적 피드백 극대화 | `liveSync: true`, `enableBBoxSnap: true`, `showConfidenceBadges: true`, `dpi: 1.5`, `autoScrollSync: true` |
| `performance` | **🚀 초고속 모드** | 대량 도서 빠른 변환 및 오버헤드 최소화 | `liveSync: false`, `enableBBoxSnap: false`, `showConfidenceBadges: false`, `dpi: 1.0`, `renderDpi: 1.0` |
| `massive_book`| **📖 대용량 메모리 절약** | 800쪽 이상 도서 OOM 방어 모드 | `lruCacheSize: 5`, `maxHistoryDepth: 50`, `autoCleanOnSave: true`, `includeSoftDeleted: false` |

## 5. 논리적 모순 및 충돌 방어 매트릭스 (Conflict Defense)

| 충돌 시나리오 | 발생 가능한 결함 | 시스템 방어 로직 (Defense Logic) |
| :--- | :--- | :--- |
| **LiveSync ON + 타이핑** | 1글자 입력마다 뷰어 Undo 스택 오염 | 교정기 내부는 `HistoryManager<BBox[]>`로 단어 단위 로컬 관리, 뷰어에는 **500ms 디바운스된 페이지 스냅샷**만 전달하여 뷰어 스택 보존. |
| **디버그 텍스트 레이어 ON + 최종 PDF 저장** | 완성본 PDF에 붉은색 글자가 인쇄되어 오염 | 메인 [Searchable PDF 다운로드] 버튼은 `opacity: 0` 강제, 디버그 모드 시 별도의 [🛠️ 디버그 레이어 PDF] 보조 버튼으로 분리. |
| **BBox 자동 스냅 ON + 1px 미세 튜닝** | 작은 특수문자/수식 BBox를 원하는 위치에 배치 불가 | `Shift` 키를 누른 채 드래그 시 스냅 로직을 0ms로 바이패스(Bypass)하여 1px 정밀 제어 허용. |
| **소프트 삭제 페이지의 OCR 교정기 진입** | 삭제된 페이지 편집 시 데이터 불일치 | 뷰어에서 교정 버튼 클릭 시 *"소프트 삭제된 페이지입니다. 복구 후 교정하시겠습니까?"* 대화상자 노출 및 자동 복원 후 진입. |
