## 1. 개요 및 설계 철학

purePDFrend의 모든 화면은 독립된 모듈 단위인 **'프로그램(Program ID)'**으로 식별 및 등록되며, 관리자 서비스의 프로그램 관리(`PG-ADM-02`) 및 메뉴 관리(`PG-ADM-06`)와 데이터베이스 레벨에서 연동된다.

```mermaid
graph TD
    Root[purePDFrend 최상위 포털] --> AGT[에이전트 서비스 도메인: PG-AGT-*]
    Root --> ADM[관리자 서비스 도메인: PG-ADM-*]
    Root --> USR[사용자 서비스 도메인: PG-USR-*]

    AGT --> AGT_Sub[4대 거버넌스 뷰]
    ADM --> ADM_Sub[16대 운영관리 뷰]
    USR --> USR_Sub[9대 핵심 사용자 뷰]
```

## 5. 계층적 정보 아키텍처(IA) 및 화면 전환 흐름도

```mermaid
stateDiagram-v2
    [*] --> PG_USR_01: 서비스 접속 (비회원/공개)
    
    PG_USR_01 --> PG_USR_02: 로그인 / 회원가입 선택
    PG_USR_01 --> PG_USR_06: 공개 문서 ID/링크 조회 열람 (읽기모드)
    
    PG_USR_02 --> PG_USR_03: 인증 완료 후 홈화면 진입
    
    state 사용자서비스 {
        PG_USR_03 --> PG_USR_04: 마이페이지 프로필 관리
        PG_USR_03 --> PG_USR_05: 문서관리 라이브러리 이동
        PG_USR_03 --> PG_USR_06: PDF 7대 도구 실행 (뷰어 직결)
        PG_USR_03 --> PG_USR_09: 환경설정 이동
        
        PG_USR_05 --> PG_USR_06: 등록 문서 열람 및 주석 편집
        PG_USR_06 --> PG_USR_07: 실시간 협업 공유뷰 열기

    state 관리자서비스 {
```

## 6. 반응형 UI/UX 배치 규격 및 모바일 최적화

1. **데스크톱 (≥ 1280px)**:
   - 상단 글로벌 네비게이션 바(GNB) 고정.
   - 좌측 네비게이션 드로어(280px), 중앙 뷰어 캔버스(가변), 우측 인스펙터 패널(320px).
2. **태블릿 (768px ~ 1279px)**:
   - 좌우 패널은 접이식 오버레이(Off-canvas Drawer)로 전환.
   - 툴바는 수평 스냅 슬라이더(`ScrollSnapCarousel`) 적용.
3. **모바일 (≤ 767px)**:
   - GNB는 햄버거 메뉴 및 단일 줄 툴바로 단순화.
   - 툴바 텍스트 완전 제거, 아이콘 전용 + 터치 타겟 최소 44px 보장.
   - 복잡한 툴바 순서 설정은 `ToolbarConfigModal` 팝업을 통해 직관적으로 제공.
