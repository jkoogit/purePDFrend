# 관리자 메타원장 대시보드 및 세션 스냅샷 파일화 아키텍처 설계 (설계 05-09)

## 1. 아키텍처 개요

본 설계는 분산된 에이전트 토큰 원장, 요금제 정책, 모델 카탈로그를 중앙에서 통합 제어하는 **메타 거버넌스 백오피스**와, 세션 행 발생 시 비-LLM 방식으로 로컬 파일 및 DB에 미완료 작업 목록을 자동 보존하는 **스냅샷 파일화 엔진**의 기술 구조를 정의합니다.

```
[클라이언트 Web UI (React SPA)]
  │
  ├── [에이전트통계 화면 (AgentUsageViewer)]
  │     ├── [상단] EmergencyRecoveryPanel (비-LLM 긴급 Push, Hang 진단, #세션복구 복사)
  │     │     └── [모달] Snapshot Residual Tasks Viewer (미완료 태스크/루프)
  │     └── [탭 전환]
  │           ├── Tab A: 대화 턴 추적 및 텔레메트리 (Conversation Trace)
  │           └── Tab B: MetaGovernanceBackoffice (4대 메타 원장 통제)
  │                 ├── 요금제 정책 4종 비교 카드
  │                 ├── 멀티 모델 카탈로그 테이블
  │                 ├── 사용자 계정 & 실시간 원장 테이블 (동결/해제, 플랜변경)
  │                 ├── 쿼터 긴급 충전(GRANT) 모달
  │                 └── 불변 감사 원장(QTX) 실시간 타임라인
  │
  └── [Express 백엔드 (server.ts)]
        ├── POST /api/agent/emergency/push (EmergencyGitPushEngine)
        ├── POST /api/agent/session/snapshot (JSON & MD 파일화 + PostgreSQL 저장)
        ├── GET /api/agent/session/snapshots & /snapshot/:id
        ├── GET /api/agent/meta/plans & models & users & ledgers
        ├── POST /api/agent/meta/ledger/toggle-freeze
        └── POST /api/agent/meta/ledger/grant
```

## 3. 행(Hang) 실시간 진단 상태 머신 매핑

| 진단 상태 | 예상 트리거 조건 | 예상 복구 조건 및 소요 시간 | UI 권장 조치 |
| :--- | :--- | :--- | :--- |
| `NORMAL` | 정상 통신 중 | 조치 불필요 | 계획된 태스크 계속 진행 |
| `HANG_OVERLOAD` | 일시적 503 오류 또는 순간 RPM 초과 | 1~3분 쿨다운 대기 후 재시도 권장 | 잠시 대기 후 재전송 |
| `HANG_QUOTA_EXHAUSTED` | 429 Quota Exceeded (일일 RPD 소진) | 한국시간 매일 16:00 (KST) 리셋 대기 | 긴급 Push 후 계정 전환 대기 |
| `HANG_CONTEXT_BLOAT` | 세션 누적 15만 토큰 초과 포화 | 신규 세션(B) 분기 인계 즉시 가능 | 긴급 Push & 스냅샷 파일화 후 신규 세션 복구 |
| `HANG_INDETERMINATE` | 10분 이상 원인 불명 무응답 | 10분 초과 시 비-LLM 우회로 가동 | 긴급 Push 후 `#세션복구` 명령 주입 |

## 4. 메타 거버넌스 원장 연동 규약

1. **원장 동결/해제 (Toggle Freeze)**:
   - `is_frozen = true`: 사용자 요청 차단 (403 Quota Frozen).
   - `is_frozen = false`: 정상 차감 복귀.
2. **긴급 쿼터 충전 (GRANT)**:
   - `total_granted_quota += tokens`, `remaining_quota += tokens`.
   - `agent_quota_transaction_log`에 `tx_type = 'GRANT'`, `reason_desc = reason` 기록.
