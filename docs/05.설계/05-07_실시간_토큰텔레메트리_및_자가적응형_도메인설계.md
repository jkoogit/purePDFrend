## 2. 4계층 실시간 텔레메트리 수학적 모델

### 2.1 토큰 휴리스틱 추정식 ($E$)
한국어, 영어, 특수문자, 코드/JSON 블록의 토큰 밀도를 반영한 가중치 수식:
$$E(\text{text}) = \left(\text{Chars}_{\text{en}} \times 0.25 + \text{Chars}_{\text{ko}} \times 0.70 + \text{Chars}_{\text{other}} \times 0.30\right) \times W_{\text{code}} \times W_{\text{model}}$$
- $W_{\text{code}} = 1.10$ (코드 블록 ```` ``` ```` 및 JSON 구조 포함 시 10% 가산)
- $W_{\text{model}}$: Gemini=1.00, Claude=1.15, OpenAI=1.05

### 2.2 텔레메트리 4대 파라미터 연산식
1. **소모 속도 ($v$)**:
   $$v = \frac{1}{N}\sum_{i=1}^{N} \text{Tokens}_i \times \alpha \quad (N \le 3)$$
2. **버스트 지수 ($B$)**:
   $$B = \frac{\text{Current Turn Tokens}}{\text{avg}(\text{recent 3 turns})}$$
3. **루프 안전 마진 ($LSM$)**:
   $$\text{Estimated Tokens Per Loop} = \max(3000, v \times 3 \times 1.5)$$
   $$LSM = \frac{\max(0, \text{Budget} - \text{Total Used})}{\text{Estimated Tokens Per Loop}}$$
4. **소진 위험 지수 ($BRI$)**:
   $$BRI = \min\left(100, \text{round}\left(\frac{\text{Total Used}}{\text{Budget}} \times 100\right)\right)$$

## 3. 자가 적응형 EMA 피드백 루프 (Self-Adaptive Feedback Loop)

세션 종료 시 실측 토큰과 초기 예측 토큰 간의 오차를 계산하여 다음 세션에 전파할 보정 계수 $\alpha_{t+1}$을 도출합니다:
$$\Delta = \frac{\text{Actual} - \text{Predicted}}{\text{Actual}}$$
$$\alpha_{t+1} = \max(0.6, \min(2.0, \alpha_t \times (1 + \eta \times \Delta))) \quad (\eta = 0.15)$$
