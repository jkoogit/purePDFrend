## 1. 개요 및 목적

본 문서는 purePDFrend 상단 글로벌 네비게이션 헤더(`Navbar`)의 Sun/Moon 다크/라이트 테마 스위처 구축과 관리자 시스템서비스 1단계(PG-ADM-01 보안 IP 관리, PG-ADM-03 사용자 계정 관리)의 실제 백엔드 Express REST API 및 PostgreSQL/로컬 스토어 듀얼 영속화 연동에 관한 상세 아키텍처 및 구현 규격을 정의합니다.

## 2. 상단 글로벌 헤더 테마 스위처 (PG-DS-01) 설계

### 2.1 동작 원리 및 상태 동기화
1. **스토리지 영속화**: `localStorage.getItem('purepdfrend_theme')` ('dark' | 'light')
2. **초기 로드 감지**:
   - 로컬 스토리지에 저장된 값이 있으면 우선 적용.
   - 없을 시 시스템 기본 설정(`window.matchMedia('(prefers-color-scheme: dark)').matches`) 감지.
3. **DOM 클래스 동기화**:
   - `document.documentElement.classList.toggle('dark', isDark)`
   - `document.documentElement.classList.toggle('light', !isDark)`
4. **44px 터치 가드레일**:
   - 모바일 및 태블릿 터치 시 44px x 44px 최소 터치 규격 확보.
   - 데스크톱 슬림 모드에서는 정밀 컴팩트 규격(32px) 지원 및 `title`/`aria-label` 완전 바인딩.
5. **와이어프레임 퀵액션 버튼**:
   - 헤더 상단에서 와이어프레임(PG-USR 1~7, PG-ADM 1~16)으로 1클릭 전환하는 퀵액션 단축 아이콘 배치.

## 3. 관리자 시스템서비스 1단계 REST API 규격

### 3.1 PG-ADM-01 보안 IP 관리 API
- **엔드포인트**:
  - `GET /api/admin/security/ips`: 화이트리스트 및 블랙리스트 IP 목록 조회
  - `POST /api/admin/security/ips`: IP 등록 (type: 'white' | 'black', ip, reason)
  - `DELETE /api/admin/security/ips`: IP 삭제 (type: 'white' | 'black', ip)
- **영속화 정책**:
  - 인메모리 캐시 및 `data/local_agent_store.json` 내 `security_ips` 메타 영속화
  - 원격 PostgreSQL 연결 시 감사 트랜잭션 기록

### 3.2 PG-ADM-03 사용자 계정 관리 API
- **엔드포인트**:
  - `GET /api/admin/users`: 관리자 등록 사용자 목록 조회 (PostgreSQL `aiagent.agent_user_account` 연계 + 로컬 시드 폴백)
  - `POST /api/admin/users`: 신규 사용자 계정 등록
  - `PATCH /api/admin/users/:id`: 사용자 권한(`roles`), 계정상태(`status`), 오프라인 토큰(`offlineAllowed`, `offlineDaysLeft`) 수정
  - `DELETE /api/admin/users/:id`: 사용자 계정 삭제 또는 비활성화
- **모바일 반응형 연동**:
  - 화면 폭 < 768px 시 테이블 형태에서 카드형(`Break-to-Card`)으로 즉시 전환되어 가로 스크롤 완전 차단.

## 4. 검증 및 보안 가드레일
1. **무중단 운영 (Zero-Hang Principle)**: 원격 DB 브릿지 오프라인 시에도 로컬 인메모리/JSON 스토어로 즉시 폴백하여 프론트엔드가 멈추지 않음.
2. **입력 검증**: CIDR 형식 및 IPv4 유효성 정규식 검증.
3. **린트 & 컴파일 무결성**: TypeScript 타입 선언과 일치 및 단위 테스트 100% 통과.
