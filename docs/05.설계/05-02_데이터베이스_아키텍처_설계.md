## 3. 6대 필수 감사 컬럼 (Audit Columns)
모든 테이블은 다음 감사 컬럼을 반드시 포함합니다:
- `created_sys`: 생성 시스템 식별자
- `created_at`: 생성 시각 (UTC 타임스탬프)
- `created_by`: 생성자 (사용자 또는 에이전트)
- `updated_sys`: 갱신 시스템 식별자
- `updated_at`: 갱신 시각 (UTC 타임스탬프)
- `updated_by`: 갱신자
- `version`: 낙관적 락(Optimistic Lock)을 위한 정수형 버전 번호
