## 1. 개요 및 목적
본 문서는 purePDFrend 프로젝트 내 모든 기술 문서의 일관성, 가독성, 추적 가능성을 보장하기 위한 문서 작성 및 편집이력 관리 표준을 규정합니다.

## 3. 파일 명명 규칙
1. **한글 명명 원칙**: 모든 마크다운 파일명은 직관적이고 표준적인 한글로 작성합니다. (특수문자는 하이픈 `-` 또는 언더스코어 `_`만 허용)
2. **코드리뷰 문서 예외 규격**: 코드리뷰 파일명은 `YYMMDD_순번_작업내용.md` 규격을 준수합니다.  
   - 예: `260917_001_바이브코딩환경_및_에이전트관리설계.md`

## 5. DB 동기화 원칙
- 모든 문서는 Git 저장소 파일과 개발DB `purepdfrend_dev.aiagent.agent_docs_meta` 테이블에 1:1로 매핑됩니다.
- 문서를 수정할 경우 SHA-256 해시와 메타데이터가 자동/수동 동기화되어 에이전트와 UI 상에서 일치된 상태를 유지해야 합니다.
