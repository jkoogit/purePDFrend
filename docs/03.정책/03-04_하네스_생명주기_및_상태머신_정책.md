# 09. 하네스 3계층 생명주기 및 상태머신 정의

## 1. 하네스 3계층 거버넌스 모델

```
[세션 (Session)]  --- (1:N) ---> [태스크 (Task)] --- (1:N) ---> [루프 (Loop)]
  (SESSION-...)                    (TASK-...)                     (LOOP-...)
  목표 및 회고 총괄               Git 브랜치 단위                 원자적 작업 단위
```

---

## 2. 5단계 상태 머신 전이 규칙

모든 계층(세션, 태스크, 루프)은 다음과 같은 일관된 5단계 상태 코드를 따릅니다:

```
[시작 (START)]
     │
     ▼
[처리 (IN_PROGRESS)]
     │
     ▼
[정리 (CLEANUP)]
     │
     ▼
[승급 (PROMOTE)]
     │
     ▼
[종료 (DONE)]
```

- **시작 (START)**: 작업 범위 및 목표가 정의되고 초기화된 상태
- **처리 (IN_PROGRESS)**: 활발하게 코드 작성, 문서화, 테스트가 수행되는 상태 (`#태스크처리` 단계)
- **정리 (CLEANUP)**: 구현 완료 후 보완턴(테스트코드, 보안점검, 리뷰문서)을 진행하는 단계
- **승급 (PROMOTE)**: Git 커밋/PR 생성 및 상위 브랜치로 반영 대기 상태
- **종료 (DONE)**: 모든 검증과 회고가 완료되어 작업이 정상 종결된 상태
