# 03-18. 목록 헤더 너비 조절, 정렬 버튼 분리 및 타이틀 중앙 정렬 UI 정책 (v1.0)

> **최초 작성일**: 2026-09-27  
> **적용 대상**: purePDFrend 전수 데이터 그리드 및 목록 테이블 (에이전트 거버넌스 및 PDF 서비스 백오피스)

---

## 📌 1. 정책 수립 배경 및 목적

기존 테이블 헤더(`<th>`) 전체에 정렬 클릭 이벤트가 바인딩되어 있을 경우, 사용자가 컬럼 경계선을 마우스로 드래그하여 열 너비(Width)를 조절하는 동작과 정렬(Sort) 클릭 이벤트가 중첩(Conflict)되어 의도치 않은 정렬 순서 변경이 빈번하게 발생하는 문제가 확인되었습니다.  
또한, 헤더 컬럼 타이틀의 정렬 기준이 일관되지 않아 시각적 안정성과 가독성이 저해되었습니다.

이에 따라 모든 데이터 목록 화면에 적용될 **3대 핵심 헤더 UI 정책**을 제정합니다.

---

## 📐 2. 3대 핵심 UI 거버넌스 규칙

### [규칙 1] 헤더 정렬 이벤트의 화살표 아이콘 격리 분리
- **`<th>` 셀 전체의 `onClick` 제거**: 헤더 셀의 빈 공간이나 텍스트를 클릭하거나 드래그할 때 정렬 이벤트가 트리거되지 않아야 합니다.
- **전용 정렬 버튼 (`renderSortButton`) 제공**:
  - 오직 정렬 상태(기본/오름차순/내림차순)를 나타내는 화살표 아이콘 버튼을 명시적으로 클릭할 때만 정렬이 실행됩니다.
  - 정렬 버튼 클릭 이벤트 핸들러에는 반드시 `e.stopPropagation()`을 적용하여 부모 이벤트 버블링을 차단합니다.
  - 3-state 순환 정렬(`init` ➔ `asc` ➔ `desc` ➔ `init`) 표준을 준수합니다.

### [규칙 2] 헤더 컬럼 너비 드래그 조절 (Column Resizing) 의무화
- **안전한 클로저 기반 리사이징 핸들러**:
  - `startResize(col, e)` 호출 시점의 파라미터를 캡슐화하여 `null` 포인터 참조 오류를 원천 차단합니다.
  - `table-fixed` 레이아웃과 개별 컬럼 `style={{ width, minWidth }}`를 설정하여 유연하고 안정적인 리사이징을 제공합니다.
  - 헤더 우측 경계선에 `cursor-col-resize` 핸들러 바(`absolute right-0 top-0 bottom-0 w-1.5`)를 배치합니다.
  - 셀 내용 넘침 방지를 위해 `truncate overflow-hidden`을 일괄 적용합니다.

### [규칙 3] 목록 헤더 타이틀 및 정렬 버튼 중앙 정렬 (Center Alignment)
- 모든 헤더 셀의 레이아웃은 기본적으로 **가운데 정렬(`text-center justify-center`)**을 표준으로 합니다.
  ```tsx
  <th style={{ width: `${colWidths[colKey]}px`, minWidth: `${colWidths[colKey]}px` }} className="p-3 text-center relative select-none">
    <div className="inline-flex items-center justify-center gap-1 w-full">
      <span className="truncate">{label}</span>
      {renderSortButton(colKey, label)}
    </div>
    <div onMouseDown={(e) => startResize(colKey, e)} className="absolute right-0 top-0 bottom-0 w-1.5 cursor-col-resize hover:bg-indigo-500/80 group-hover:bg-slate-700" />
  </th>
  ```
