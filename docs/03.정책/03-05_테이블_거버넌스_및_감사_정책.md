# 15. 테이블 거버넌스 및 감사 규정

## 1. 개요
데이터베이스의 무결성과 추적성을 확보하기 위해 `purepdfrend_dev`의 모든 영속화 테이블에 적용되는 거버넌스 원칙을 규정합니다.

---

## 2. 6대 감사 컬럼 필수 정의

모든 DDL 생성 시 다음 6개 컬럼은 생략할 수 없습니다:

1. `created_sys VARCHAR(50) NOT NULL`: 최초 생성 시스템
2. `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`: 최초 생성 일시
3. `created_by VARCHAR(100) NOT NULL`: 최초 생성 주체
4. `updated_sys VARCHAR(50) NOT NULL`: 최종 수정 시스템
5. `updated_at TIMESTAMPTZ NOT NULL DEFAULT now()`: 최종 수정 일시
6. `updated_by VARCHAR(100) NOT NULL`: 최종 수정 주체

---

## 3. 동시성 제어 및 낙관적 락 (Optimistic Lock)
- 모든 갱신 대상 테이블에는 `version INT NOT NULL DEFAULT 1` 컬럼이 추가됩니다.
- 레코드 수정 시 `WHERE id = :id AND version = :current_version` 조건과 함께 `version = version + 1` 처리를 수행하여 동시 수정 충돌을 원천 방지합니다.
