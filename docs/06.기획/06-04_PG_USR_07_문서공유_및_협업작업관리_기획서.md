## 1. 기획 배경 및 문제의식

### 1.1 기존 구현의 한계 (시나리오 점프 결함)
- 기존 `PG-USR-07` 화면은 특정 문서가 선택되지 않은 채 단일 링크 1개와 고정된 협업자 3명만 표시되어 사용자의 진입 흐름(User Journey)과 단절되는 문제가 존재함.
- 실제 사용자는:
  1. `PG-USR-05 (문서관리)` 목록에서 단일 문서 또는 **다중 문서를 일괄 선택**하여 공유 링크를 발급하거나,
  2. `PG-USR-06 (문서뷰어)`에서 현재 열람 중인 문서를 공유하기를 원함.
  3. 독립된 메뉴 프로그램인 `PG-USR-07`에서는 **내가 공유한 문서(제공)와 초대받은 문서(참여)의 전체 현황을 대시보드로 조회 및 통제**하고, 특정 문서의 작업현황을 **'문서작업현황 팝업'**을 통해 상세 모니터링해야 함.

## 2. 핵심 기능 명세

### 2.1 [공유관리] vs [사용관리] 2대 탭 체계
1. **📤 공유 관리 (제공자 관점)**:
   - 내가 발급한 공유 링크 목록 표시 (카테고리, 문서, 버전)
   - 권한 수정, 링크 복사, 공유 회수(Revoke / Soft Delete)
   - 미접속 링크는 물리 삭제, 접속 이력 존재 시 권한 회수 및 비활성화 처리
2. **📥 사용 관리 (참여자 관점)**:
   - 내가 초대받아 참여 중이거나 만료된 문서 목록
   - 열람 권한, 소유자 정보, 최초 개시일 및 최종 작업일 표시
   - 만료 시 문서는 열람 불가하며 이력만 유지되고 `[📩 공유 재요청]` 버튼 제공

### 2.2 검색 및 다차원 필터 바
- **공유대상**: `전체` / `단일 문서` / `카테고리(폴더)` / `특정 버전`
- **부여권한**: `전체` / `열람자(읽기)` / `검토자(주석달기)` / `공동편집자(전체권한)`
- **공유기간**: `전체` / `유효함` / `7일 이내 만료임박` / `만료됨` / `무제한`
- **사용여부/상태**: `전체` / `활성중` / `미사용(미열람)` / `회수완료`
- **통합 검색**: 문서명, 수신자 이메일/닉네임 검색

### 2.3 문서작업현황 팝업 (Collaboration Studio Modal)
- **문서 공유 메타**: 문서명, 버전(v1.2 등), 소유자, 참여자 수, 권한, 유효기간(D-Day), 비밀번호 보호 상태
- **실시간 작업자 목록**:
  - 프로필 아바타, 닉네임, 역할
  - 실시간 상태 아이콘 (🟢 온라인 실시간 작업중, 🟡 15분 이상 유휴, ⚪ 오프라인)
  - 현재 열람 페이지 칩 (`[p.14 형광펜 ➔]`) 클릭 시 `PG-USR-06` 뷰어의 해당 쪽수로 즉시 점프
  - 작업자 클릭 시 우측 피드가 해당 작업자의 활동 내역으로 필터링
- **시간대별 4단계 활동 피드 (Grouped Live Feed)**:
  - `방금 전` ➔ `10분 전` ➔ `7일 전` ➔ `오래 전` 그루핑
  - 피드 로그 클릭 시 해당 페이지로 즉시 이동 및 주석 펄스(Pulse) 하이라이트

### 2.4 뷰어(`PG-USR-06`) 주석 협업 UX
- **작성자 라벨 토글 버튼**:
  - `[🏷️ 작성자 라벨]` 토글 ON 시 모든 주석 끝에 아바타+이름 라벨 표시
  - OFF 시 깔끔한 원문 유지, 마우스 호버(PC) 또는 롱프레스(모바일) 시 작성자 툴팁 노출
- **작성자별 주석 검색 & 일괄 삭제**:
  - 주석 패널에서 작성자별 필터링
  - 소유자/관리자 전용 `[작성자 주석 일괄 삭제]` 액션 제공
- **권한 강등 가드**:
  - 작업 중 소유자가 권한을 회수한 경우 즉시 읽기 전용으로 전환되고 경고 토스트 노출

### 2.5 비로그인 게스트 ➔ 로그인 권한 승급 세션 핸드오프 (Session Handoff)
- 공개 읽기 링크로 비로그인 상태 열람 중 로그인 시, `sessionStorage`에 보존된 공유 토큰을 유지하여 로그인 완료 즉시 정식 권한 뷰어로 복귀.
