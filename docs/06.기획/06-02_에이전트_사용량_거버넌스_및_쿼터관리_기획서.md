## 1. 기획 배경 및 요구사항

### 1.1 사용자 페인 포인트
- 에이전트와 장시간 협업 중 언제 토큰이 소진되어 대화가 끊길지 알 수 없어 불안감 가중.
- 세션 종료 후 다음 세션으로 넘어갈 때 이전 세션에서 진행 중이던 태스크 및 백로그가 소실되어 다시 지시해야 함.

### 1.2 핵심 기능 목표
1. **연료 게이지(`TokenBurnoutGauge`)**: 실시간 잔여 토큰, BRI 위험도, 안전 루프 마진($LSM$)을 직관적으로 시각화.
2. **원클릭 인계 도시에 모달(`HandoffDossierModal`)**: $BRI \ge 85\%$ 도달 시 또는 수동 인계 요청 시, Git 3대 기준점과 미완료 백로그가 담긴 프롬프트를 원클릭으로 복사 및 세션 연장 실행.
3. **자가 적응형 스코어카드 모달(`ScorecardModal`)**: 세션 종료 시 토큰 계산 정확도(MAPE), 보정 가중치($\alpha$), 내부 API 오프로딩 추천 내역을 보고서 형태로 열람.

## 2. 화면 인터랙션 및 UX 사양

```
+-----------------------------------------------------------------------------------+
| [🔥 토큰 소진 위험 지수 (BRI)]  32% [SAFE]   남은 루프 마진: 12 loops              |
| [========================>------------------------------------------------------] |
| 속도: 1,420 tokens/turn | 버스트: 1.05x | 차기 보정치(α): 1.05                      |
| [인계 도시에 생성]  [세션 스코어카드 산출]                                          |
+-----------------------------------------------------------------------------------+
```

- **상태별 색상**:
  - `SAFE` (<70%): 에메랄드 그린 (`emerald-500`)
  - `CAUTION` (70~85%): 앰버 옐로우 (`amber-500`)
  - `CRITICAL` (≥85%): 로즈 레드 (`rose-500`)
- **터치 및 반응형 대응**: 모바일 뷰에서도 가로 스크롤 없이 카드 형태로 자연스럽게 축약 노출.
