## 1. 개요 및 변경 배경

기존 와이어프레임 `PG-USR-03(홈화면 대시보드)`는 일반 사용자가 주로 사용하는 메인 화면임에도 상단 프로필 영역에 관리자/에이전트 서비스 이동 버튼이 큰 텍스트 버튼으로 상시 노출되어 시각적 잡음이 컸으며, 7대 PDF 핵심 문서 도구 카드가 정적 그리드로만 머물러 있어 실제 작업 페이지로의 전이가 이루어지지 않았습니다.

이를 개선하여:
1. **헤더 영역 간소화**: 관리자 및 에이전트 서비스 이동 버튼을 권한 보유자(`ROLE_SYSADMIN`)에게만 설정 버튼 옆에 직관적이고 깔끔한 미니멀 아이콘(`Bot`, `ShieldCheck`, `Settings`)으로 정돈하여 배치합니다.
2. **7대 PDF 문서도구 전용 작업화면(인라인 서브페이지) 구현**: 7개 도구 카드 클릭 시 대시보드 내부가 전용 작업화면으로 부드럽게 전환되며, 파일 드롭존, 도구별 옵션 설정, 실행 시뮬레이션 및 상단 `← 대시보드로 돌아가기` 네비게이션을 완비합니다.

## 2. 7대 PDF 도구 전용 작업화면 사양

| 번호 | 도구 ID | 도구명 | 핵심 기능 및 작업화면 구성 |

| 1 | `tool-camera` | 📷 카메라 문서스캔 | 웹캠/카메라 뷰파인더 가이드, A4 비율 감지, 즉시 촬영, 다중 썸네일 스트립, PDF 변환 |
| 2 | `tool-img2pdf` | 🖼 이미지 ➔ PDF | 다중 이미지 업로드 드롭존, 순서 재배열, 회전, 용지 크기/방향/여백 설정, PDF 병합 |

| 4 | `tool-ocr2text` | 📝 PDF OCR ➔ TEXT | 페이지 범위 지정, 원문/추출 텍스트 좌우 Split 뷰, 클립보드 복사, .txt / .md 다운로드 |

| 6 | `tool-compress` | 🗜 PDF 압축 | 원본 크기 분석, 3단계 압축 프로필(고품질/권장/최대), 절감률(%) 게이지, 용량 비교 |
| 7 | `tool-security` | 🔒 PDF 보안 | 열람 암호 및 마스터 암호, 세부 권한 제어(인쇄/복사/주석), AES-256 암호화 적용 |

## 3. UI/UX 디자인 가이드라인 (Anti-AI Slop & Minimal Header)

- **헤더 아이콘 버튼 그룹**:
  - `Bot`: AI 에이전트 하네스/대화 관리 서비스 (인디고 링 호버, 툴팁 제공)
  - `ShieldCheck`: 시스템 및 OCR 관리자 서비스 (에메랄드 링 호버, 툴팁 제공)
  - `Settings`: 마이페이지 / 환경설정 바로가기 (`PG-USR-09` 연동)
- **전용 작업화면 상단 공통 네비게이션**:
  - `← 7대 도구 대시보드로 돌아가기` 버튼으로 단일 클릭 즉시 복귀
  - 도구 배지 및 가이드 문구 제공
- **반응형 뷰포트**:
  - 모바일, 태블릿, 데스크톱 전 해상도에서 1줄 슬라이드 및 유연한 그리드 레이아웃 유지.
